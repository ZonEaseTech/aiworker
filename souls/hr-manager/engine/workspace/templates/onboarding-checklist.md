## 首日 checklist

- [ ] 账号与设备、权限（GitHub / 飞书 / 服务器 / 数据库按需最小授予）、IM / 邮箱
- [ ] 工位、门禁、报销 / 考勤须知
- [ ] 必读：团队介绍、TTPOS 产品概览（10 终端 / 多租户 / 出海）、协作规范（飞书 + GitHub + ttpos-bot）、合规与信息安全
- [ ] 与直属上级 1:1（期望对齐）

## 首周 checklist

- [ ] 核心工具 / 代码库 / 文档体系上手；**工程师跑通本地环境**（Go `go mod tidy` 连本地 MySQL/Redis 或 Flutter `melos bootstrap` + `build_runner` 某终端）
- [ ] 读懂领域术语（开台 / 转台 / 对账 / 堂食打包外送）与多租户约定（saas + `shop{uuid}`）
- [ ] 关键干系人 1:1（列名单 + 目的）
- [ ] 完成第一个小任务（low-risk、可快速反馈；走能过 ttpos-bot 质量门的 issue / PR 流程）
