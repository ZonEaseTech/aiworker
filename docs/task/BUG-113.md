# BUG-113 Session route return action should go back to worker

- **status**: completed
- **priority**: P0

- **claimedAt**: 2026-05-12 00:00

## 背景

Worker Web 在未选中 session 的 workspace route 中显示“返回 worker”，并导航回
`/workers/:workerId`。选中 session 后，左侧上下文卡片和聊天头部显示“返回工作区”，
会回到 workspace route。当前产品反馈要求 session route 与未选中 session 时保持一致：
返回动作应直接回到 worker。

## 目标

将 session route 的返回动作统一为“返回 worker”，并保持导航效果与 workspace route
中的返回 worker 一致。

## 验收标准

- `/workers/:workerId/workspaces/:workspaceId/sessions/:sessionId` 左侧上下文卡片显示
  “返回 worker”。
- session 聊天头部返回按钮显示“返回 worker”。
- 点击 session route 的返回 worker 会导航到 `/workers/:workerId`。
- session route 不再显示“返回工作区”。
