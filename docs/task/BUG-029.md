# BUG-029 Gateway start fails in a clean cwd without a preexisting data directory

- **status**: completed
- **priority**: P1
- **owner**: Unassigned
- **createdAt**: 2026-04-28 20:15
- **discoveredAt**: 2026-04-28 20:15
- **releaseTarget**: `@zonease/aiworker-cli@0.4.4`
- **bkd**: 4xtxnd93

## Description

`aiworker gateway start` does not satisfy the zero-env quickstart path when it
is started from a clean current working directory that lacks `./data`.

Observed behavior:

1. A clean temp cwd with only `AIWORKER_HOME=/tmp/.../home` was used.
2. Running `bun apps/cli/dist/aiworker.js gateway start --port 43219` exited
   with status `1`.
3. The user-facing error was `gateway start 失败: unable to open database file`.
4. Running the same command shape with
   `AIWORKER_FLEET_DB_PATH=/tmp/.../fleet.db` started successfully, and
   `GET /health` returned HTTP 200 with `{"ok":true,"service":"aiworker-gateway"}`.

Root cause candidate:

- [packages/gateway/src/config.ts](/home/ben/projects/aiworker/packages/gateway/src/config.ts:63)
  defaults `AIWORKER_FLEET_DB_PATH` to `./data/fleet.db`.
- The gateway start path does not create the parent directory before opening
  SQLite, so a clean cwd fails unless the operator already created `./data` or
  provided an explicit DB path.

## Acceptance Criteria

1. `aiworker gateway start` succeeds from a clean cwd without requiring the
   operator to create `./data` manually.
2. The default fleet DB location is derived from a stable AIWorker data home or
   its parent directory is created before SQLite opens the file.
3. The failure mode, if the DB path is not writable, names the resolved path and
   provides an actionable message.
4. Add a regression test or CLI smoke that starts the gateway with a clean temp
   cwd and no explicit `AIWORKER_FLEET_DB_PATH`.
5. Preserve the ability to override the DB with `AIWORKER_FLEET_DB_PATH`.

## ActiveForm

Making gateway quickstart create or default its fleet DB directory correctly
