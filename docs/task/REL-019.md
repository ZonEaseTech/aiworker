## 描述

发布 `@zonease/aiworker-cli@0.9.3`，作为 `0.9.2` 之后的 patch release，
交付 `FEAT-055 / PLAN-134` 的 worker-local gateway enrollment env 持久化。

本次发版包含：

- `bootstrapDotenv()` 从当前 scope 的 `.env` 读取
  `AIWORKER_GATEWAY_URL` / `AIWORKER_JOIN_TOKEN` / `AIWORKER_DISPLAY_NAME` /
  `AIWORKER_ENROLL_MODE`。
- 显式 process env 中的上述 worker 入网启动项会合并回当前 scope 的 `.env`，
  保持当前进程显式 env 优先，同时让后续启动不依赖 shell 会话。
- project worker 推荐使用 `<project>/.aiworker/local/.env` 保存本机私有
  gateway/display/enroll startup env；systemd / docker 仍可用各自进程 env。
- README / CLI / deployment / architecture docs 明确 `AIWORKER_HOME` 是
  worker runtime state root，`config.yaml` 仍是 redacted advisory mirror。
