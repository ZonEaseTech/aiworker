## Description

代码审查（root issue: `nnid9urk`）发现的 P1 安全问题。

### 现象

gateway loopback 连接（`127.0.0.1` / `::1` / `::ffff:127.0.0.1`）一律放行无 token
（`packages/gateway/src/auth/loopback.ts` + `packages/gateway/src/auth/token.ts`
`authorizeConnection` 第 86-87 行）。CLAUDE.md 与 `docs/task/BUG-007.md` 已注明
公网部署必须叠 Caddy basic-auth 否则反代后所有流量看起来都是 loopback。

### 风险

运维一旦漏配 basic-auth，外网 operator 直连可：

- `workers.list` / `workers.pair` / `workers.launch`
- `token.rotate`（轮换其它 worker 的 token）
- `enroll.approve` / `enroll.reject`

文档约定不是 fail-closed —— 这条实质上是"依赖运维不出错"。

### Acceptance criteria

1. gateway start 时检查：若 `host` 是 `0.0.0.0` 或非 loopback hostname，且
   `internalSharedSecret` 未配置（环境变量 `INTERNAL_SHARED_SECRET` 缺失），直接
   `throw` 拒绝起 server。
2. 错误信息明确提示二选一：要么绑 `127.0.0.1` + Caddy basic-auth，要么配
   `INTERNAL_SHARED_SECRET`。
3. loopback bind（`127.0.0.1` / `::1` / `localhost` / `127.x.x.x`）+ 无 secret 仍
   允许（向后兼容本机 dev / smoke / 已部署的 systemd loopback 实例）。
4. 单元测试覆盖：loopback bind ± secret / `0.0.0.0` ± secret / `::` / 公网 IP /
   错误信息文案。

## Notes

### 实现位置

- `packages/gateway/src/auth/loopback.ts` — 新增 `assertGatewayBindIsSafe()`
  helper（与 `isLoopbackAddress` 同文件，loopback 语义聚合）。
- `packages/gateway/src/server.ts` — `startGatewayServer()` 入口顶部调用，先于
  `Bun.serve()` bind 端口；失败 throw 由 CLI（`apps/cli/src/aim/commands/gateway.ts`
  `runGatewayStartForeground` 的 `catch`）捕获，写 `consola.error` 后返回 exit
  code 1。
- `packages/gateway/test/auth.test.ts` — 新增 `describe('assertGatewayBindIsSafe')`
  组，覆盖 loopback / public / IPv6 any / secret 缺失等八条用例。

### 不在本 issue 范围（留 follow-up）

- **Source IP 信任**：当前 `serverRef.requestIP(req).address` 是 TCP socket 远端，
  反代后看起来真的是 loopback——这无法从代码层面分辨。本断言**不修复**这个根因，
  只兜"绑公网 + 没密钥"这种最明显的 misconfig。
- 长期方向：`X-Forwarded-For` 检查；或让 Bun.serve 同时监听一个 unix socket 给
  aim CLI loopback 用，TCP 端口必须有 sharedSecret——拆独立 issue。

### 与 BUG-007 的关系

- BUG-007 修运维侧：Caddy 反代必须叠 basic-auth，否则 Caddy 拒载 → fail-closed。
- BUG-019 修代码侧：gateway 进程启动时先验自身 bind 安全，错配 → fail-closed。
- 两条防线不重叠。BUG-019 不能替代 BUG-007（loopback 反代欺骗仍存在），但能拦
  "0.0.0.0 + 没 secret"这种最差路径。
