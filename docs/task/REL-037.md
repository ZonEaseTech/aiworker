## 背景

`@zonease/aiworker-cli@0.15.2` 已发布，npm latest 与 GitHub Release 均指向
`0.15.2`。当前 `main` 之后的 Soul App authoring layout v2 改动引入了新的
`engine-assets/`、`product/`、`host-adapter/` 作者布局，新增 workspace/native skill/MCP
client projection 合同，并让 scaffold、validate、runtime、SDK 与官方 HR/QA apps 对齐。

这改变了 0.x preview 的公开 Soul App authoring surface，适合作为 `0.16.0` minor preview
release 发布。

## 范围

- 将 CLI package version 从 `0.15.2` bump 到 `0.16.0`。
- 运行本地 source/build/dist/pack/smoke release gates。
- 提交 release prep commit。
- 推送 `main` 与 annotated tag `v0.16.0`。
- 监控 tag-triggered GitHub Actions release workflow。
- 验证 npm latest、显式 package smoke、GitHub Release tarball/checksum assets
  与 published-package preview smoke。
- 更新本任务、`PLAN-336`、索引文件与 `docs/changelog.md` 的 release evidence。

## 非范围

- 不发布 `@zonease/aiworker-soul-app-sdk` 或
  `@zonease/aiworker-soul-app-runtime` 独立 npm 包。
- 不声明 1.0 GA。
- 不新增 Host auth、cloud marketplace、gateway/fleet 或远程控制面 scope。
- 不重写 `0.15.2` release tag 或 npm package。

## 验收标准

1. 本地 release gate 全部通过。
2. `apps/cli/package.json` 与 `apps/cli/dist/package.json` 均报告 `0.16.0`。
3. `npm pack --dry-run --json` 证明 CLI shims、Worker Web static、worker
   migrations 与官方 HR/QA app release resources 进入发布包。
4. `smoke:dist-release` 证明 dist CLI 能启动 Host Web/API、bootstrap official
   HR/QA Soul Apps，并能发现 HR template。
5. `main` 与 `v0.16.0` 推送成功。
6. GitHub Actions release workflow 成功。
7. npm latest 解析到 `0.16.0`。
8. `bunx @zonease/aiworker-cli@0.16.0 --version` 报告 `aiworker/0.16.0`。
9. GitHub Release `v0.16.0` 存在且含四个平台 binary tarballs 和四个
   matching `.sha256` checksum assets。
10. Published-package smoke 证明已发布 CLI 的 Host/Soul App preview path 可用。

## 残余风险

- 这次 release 覆盖公开 Soul App authoring layout，风险高于普通 patch release；本地 gate
  必须覆盖 scaffold、validate、runtime、SDK、dist package 与 published-package preview path。
- 如果 GitHub Actions release workflow 在 npm publish 前失败，保持任务打开并在诊断后用干净
  tag 策略重试。
- 如果 npm 已发布但 post-release smoke 失败，不覆盖 `0.16.0`，记录缺陷并准备后续 patch。
- GitHub Actions release workflow 仍报告既有 Node.js 20 actions deprecation
  annotation，涉及 `actions/setup-node@v4` 和 `softprops/action-gh-release@v2`。
  该注解未阻塞 `0.16.0` 发布。
