# DOC-011 Converge Host and Soul App architecture entrypoints

- **status**: completed

## 背景

Host / Soul App 双自治讨论已经收敛为新的产品与架构边界：Host 是平台定位、能力壳、
安装启用、安全、设置、broker 与 shell 合同提供方；Soul App 是垂直领域状态、领域意义、
artifact/profile/review/lesson 语义和独立运行体验的主权方。

现有 `GOALS.md`、`docs/architecture.md`、根 `AGENTS.md` 与 Soul App authoring 文档仍混有
旧的 worker loop、Host-owned artifact/review/memory 和治理残留语义，后续开发会被这些入口
拉回旧方向。

## 目标

1. 删除 `GOALS.md`，不保留 redirect stub。
2. 将 `docs/architecture.md` 改为唯一架构合同，明确 Host / Soul App / protocol 三方边界。
3. 将根 `AGENTS.md` 改为执行指南，移除旧北极星入口和干扰项。
4. 同步 Soul App skill 与 developer guide，确保 agent-native authoring 规则读取同一套边界。
5. 更新仍在当前入口中暴露旧语义的 README 与 governance 状态说明。

## 非目标

- 不修改运行时代码、manifest schema、API、DB migration、CLI 行为或 Web UI。
- 不重写历史 PMA、changelog、Superpowers spec/plan 记录。
- 不恢复旧 gateway/fleet/control-plane/generic runtime 叙事。

## 验收标准

- 当前开发入口只要求阅读 `AGENTS.md` 与 `docs/architecture.md`。
- `GOALS.md` 已删除。
- 活跃文档不再声明 Host 默认拥有领域 artifact/review/memory/profile 语义。
- Soul App authoring 文档说明 Host 只能消费 Soul App 通过协议暴露的 view/action/status。
- `git diff --check` 通过。

## 完成记录

- 删除 `GOALS.md`，把当前架构入口收敛为根 `AGENTS.md` 与 `docs/architecture.md`。
- 重写 `docs/architecture.md`，明确 Host 是平台定位与能力壳，Soul App 是领域主权方，
  Host 只能消费协议暴露的 app-owned surfaces。
- 重写根 `AGENTS.md`，保留 agent 执行规则、当前实现地图、边界约束、UI/API 规则和验证命令。
- 同步 Soul App developer skill、authoring guide、README 与 governance 状态说明，移除旧
  Host-owned artifact/review/memory 默认语义。
