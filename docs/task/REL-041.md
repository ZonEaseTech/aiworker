## 背景

`FEAT-096 / PLAN-354` 已完成 HR People Workbench 的 Profile Patch Review
改造，并已 fast-forward 合并到本地 `main`。本地 `main` 同时包含 Host shell V9
和 Host/Soul workbench contract cleanup 等尚未发布到 npm latest 的变更。

当前 npm latest 为 `@zonease/aiworker-cli@0.17.1`，远端最新 `v0.17.x` tag
为 `v0.17.1`。本任务发布 `0.17.2` patch release，让 HR Reading Room /
Profile Patch Review / Next Step panel 改造进入 npm latest 与 GitHub Release。

## 范围

- 将 CLI package version 从 `0.17.1` bump 到 `0.17.2`。
- 运行本地 release gates，覆盖 full check/test/build、dist package、pack
  dry-run、dist release smoke 与 code-review-graph。
- 提交 release prep commit。
- 推送 `main` 与 annotated tag `v0.17.2`。
- 监控 tag-triggered GitHub Actions release workflow。
- 验证 npm latest、显式 `bunx` 版本、GitHub Release assets 与
  published-package smoke。
- 更新本任务、`PLAN-355`、索引文件与 `docs/changelog.md` 的 release
  evidence。

## 非范围

- 不扩展 HR workbench 功能范围。
- 不重写 `v0.17.1` tag 或 npm package。
- 不改变 Host/Soul App 协议边界。

## 验收标准

1. 本地 release gate 全部通过。
2. `apps/cli/package.json` 与 `apps/cli/dist/package.json` 均报告 `0.17.2`。
3. `npm pack --dry-run --json` 证明 Worker Web、official HR/QA app resources
   与 CLI dist 进入发布包。
4. `smoke:dist-release` 证明 dist CLI 能启动 Host Web/API、bootstrap official
   HR/QA Soul Apps，并成功调用 HR `create-people-profile` 与 QA
   `create-release-gate` mounted actions。
5. `main` 与 `v0.17.2` 推送成功。
6. GitHub Actions release workflow 成功。
7. npm latest 解析到 `0.17.2`。
8. `bunx @zonease/aiworker-cli@0.17.2 --version` 报告 `aiworker/0.17.2`。
9. GitHub Release `v0.17.2` 存在且含四个平台 binary tarballs 和四个 matching
   `.sha256` checksum assets。
10. Published-package smoke 证明已发布 CLI 可启动 Host Web/API、bootstrap
    official HR/QA Soul Apps，并调用 HR/QA mounted actions。
