# BUG-030 Fleet and worker admin mobile layouts overflow under narrow viewports

- **status**: completed
- **priority**: P2
- **owner**: Unassigned
- **createdAt**: 2026-04-28 20:15
- **discoveredAt**: 2026-04-28 20:15
- **releaseTarget**: `@zonease/aiworker-cli@0.4.4`
- **bkd**: 2q45cah8

## Description

The Fleet and Worker admin UIs render, but the shells are not usable on a
390px mobile viewport. Their fixed left sidebars remain visible at full width
and compress the main content into an extremely narrow column.

Observed behavior from Playwright screenshots against a local 0.4.4 gateway:

1. `GET /admin/` and JS/CSS assets returned HTTP 200 for both fleet and worker
   admin bundles.
2. Desktop 1440x900/1440x1000 rendering was usable for checked routes.
3. Mobile 390x844 rendering showed a fixed full sidebar taking most of the
   viewport width.
4. `/admin/`, `/admin/enroll`, `/admin/audit`, and `/admin/presence` all
   suffered severe text wrapping, clipped cards, or horizontally overflowing
   controls. The `/admin/` empty state button extended beyond the visible main
   column.
5. Worker `/admin/` and `/admin/chat` mobile captures also showed clipped or
   pushed-offscreen content.

- Worker routes have the same shell pattern and showed the same narrow-viewport
  compression in the UI smoke report.

## Acceptance Criteria

1. Fleet and Worker admin provide usable mobile layouts at 390x844 and 430x932.
2. Navigation collapses, moves to a top/bottom pattern, or otherwise stops
   reserving a fixed 240px sidebar on narrow screens.
3. Fleet Workers, Enrollments, Audit, and Presence routes do not clip primary
   content or controls at mobile widths.
4. Worker Overview and Chat routes do not clip primary content or controls at
   mobile widths.
5. Add visual or DOM-level regression checks for both admin shells at a narrow
   viewport, covering at least one primary route in each bundle.
6. Preserve the current desktop layout quality.
