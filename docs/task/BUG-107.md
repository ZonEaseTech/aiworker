# BUG-107 Workspace rail width differs between session states

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-12 01:24
- **plan**: PLAN-265
- **relatesTo**: apps/web

## 背景

Workspace route 和 session route 都使用 340px sidebar，但 session route 在桌面态额外将
`.entry-side` 横向 padding 改为 16px；未选中 session 的 workspace route 使用默认 18px。
这导致左侧 rail 内部 card、list item 和 section head 在选中/未选中 session 时宽度不一致。

## 目标

统一选中 session 与未选中 session 两种状态下左侧导航内部元素的视觉宽度。

## 验收标准

- 桌面态 workspace route 与 session route 的 `.workspace-rail-card` 宽度一致。
- 两种状态的 `.rail-session-item`、`.rail-section-head`、`.rail-empty` 宽度一致。
- 保留移动端 session route 的压缩布局规则。
- 更新浏览器验证和 code-review-graph 审查记录。
