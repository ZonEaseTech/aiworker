# BUG-100 其他工作区列表包含当前工作区

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-11 18:02
- **plan**: PLAN-258
- **relatesTo**: apps/web

## 背景

Workspace 侧栏中的“其他工作区”区块用于快捷跳转到同一 worker 下的其他工作区，
或创建新工作区。但当前实现直接渲染 `soulWorkspaces`，没有排除当前选中的
workspace，导致当前工作区也出现在“其他工作区”中并被标记为 active。

## 目标

“其他工作区”只展示同一 worker 下除当前 workspace 外的工作区。

## 验收标准

- 当前 workspace 不再出现在“其他工作区”列表中。
- 其他 workspace 仍可作为快捷跳转按钮。
- 没有其他 workspace 时显示空态，并保留“新建工作区”按钮。
- 更新测试、浏览器验证和 code-review-graph 审查。
