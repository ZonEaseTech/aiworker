# BUG-095 Worker Web worker/workspace pages are width constrained

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-11 16:42
- **plan**: PLAN-253
- **relatesTo**: apps/web

## Background

Worker and workspace routes used a special non-session selector that constrained
the header and content to `min(1120px, calc(100% - 56px))` with auto margins.
Session routes did not use that constraint, so the route shell felt inconsistent
between worker/workspace pages and session pages.

## Goal

Use the same full-width page shell for worker, workspace, and session routes.

## Acceptance Criteria

- Remove non-session route width and auto-margin constraints.
- Keep normal route padding through shared `.entry-header` and
  `.entry-tab-content` rules.
- Do not change session route behavior.
- Verify worker and workspace routes render full width in browser.
- Run focused Web validation and code-review-graph before closure.
