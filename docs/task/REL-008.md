## Description

发布 `@zonease/aiworker-cli@0.4.11`，作为 `0.4.10` 之后的 patch release，并把测试服 (`aissh aiwork`) 升级到该版本。

本次发版包含 `0.4.10` 之后已合入 main 的改动：

- FEAT-042 / PLAN-051：Orchestrator 控制执行器与任务执行器解耦。
- FEAT-043：`aiworker init` 后引导与 Soul 能力测试流程优化。
- FEAT-044：Executor capability 投影命令、capability 校验与 dry-run。
- BUG-006 / PLAN-061：`reloadRuntime` 内部串行化，避免热重载 swap race。
- BUG-038 / PLAN-059：worker info `runtimeVersion` 与发布 CLI 版本对齐。
- REFACTOR-013：稳定 CLI test gate 并拆分 Soul preset 模块。
- REFACTOR-014 / PLAN-060：CLI 内部 operator 模块脱离 `aim` 旧前缀。
- DOC-003 / DOC-004：声明 brain 与 executor 能力边界、清理陈旧 PMA 待办状态。

Release checklist：

1. 把 CLI package 版本从 `0.4.10` bump 到 `0.4.11`。
2. 跑完本地 release quality gates。
3. 构建 publish artifact，并确认 `apps/cli/dist/package.json` 报告 `0.4.11`。
4. 通过现有 tag-triggered GitHub release workflow 发布。
5. 验证 npm `latest` 解析到 `0.4.11`，并 smoke 已发布 CLI。
6. 测试服 (`aissh aiwork`) `bun install -g @zonease/aiworker-cli@0.4.11 && systemctl restart aiworker-gateway`，验证 `aiworker --version` 与 gateway `/health`。
