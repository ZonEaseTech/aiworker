# BUG-110 Count badges should be title text

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-12 01:48
- **plan**: PLAN-268
- **relatesTo**: apps/web

## 背景

Worker home 中的 count 使用独立 `count-pill` badge，视觉上像 tag。用户要求 count 改成
简单文本，并以 `(NUM)` 跟随在对应 title 后。

## 目标

将 count badge 收敛为 title 文本的一部分。

## 验收标准

- 能力模板标题显示为 `Capability template (N)` / 对应 locale 文案加 `(N)`。
- 工作区标题显示为 `Workspaces (N)` / 对应 locale 文案加 `(N)`。
- 不再渲染 `.count-pill`。
- 更新测试、浏览器验证和 code-review-graph 审查记录。
