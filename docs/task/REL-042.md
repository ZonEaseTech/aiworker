# REL-042 发布 aiworker CLI 0.17.3

- **status**: in_progress
- **priority**: P0
- **owner**: codex
- **createdAt**: 2026-05-18
- **claimedAt**: 2026-05-18
- **plan**: PLAN-357
- **relatesTo**: BUG-135, PLAN-356, v0.17.2

## 背景

`BUG-135 / PLAN-356` 已修复两个 `0.17.2` 发布后的 Web 回归：

1. HR Profile Patch Review 在真实 unfenced `person-profile` artifact 下无法从
   Web 批准写入 `README.md`。
2. session route 缺少直接返回父 workspace / Soul workbench 的导航。

当前 npm latest 为 `@zonease/aiworker-cli@0.17.2`，远端最新 `v0.17.x` tag
为 `v0.17.2`。本任务发布 `0.17.3` patch release。

## 范围

- 将 CLI package version 从 `0.17.2` bump 到 `0.17.3`。
- 运行本地 release gates，覆盖 full check/test/build、dist package、pack
  dry-run、dist release smoke 与 code-review-graph。
- 提交 release prep commit。
- 推送 `main` 与 annotated tag `v0.17.3`。
- 监控 tag-triggered GitHub Actions release workflow。
- 验证 npm latest、显式 `bunx` 版本、GitHub Release assets 与
  published-package smoke。
- 更新本任务、`PLAN-357`、索引文件与 `docs/changelog.md` 的 release
  evidence。

## 非范围

- 不继续扩大 HR workbench UI 改造。
- 不重写 `v0.17.2` tag 或 npm package。
- 不改变 Host/Soul App 协议边界。

## 验收标准

1. 本地 release gate 全部通过。
2. `apps/cli/package.json` 与 `apps/cli/dist/package.json` 均报告 `0.17.3`。
3. `npm pack --dry-run --json` 证明 Worker Web、official HR/QA app resources
   与 CLI dist 进入发布包。
4. `smoke:dist-release` 证明 dist CLI 能启动 Host Web/API、bootstrap official
   HR/QA Soul Apps，并成功调用 HR/QA mounted actions。
5. `main` 与 `v0.17.3` 推送成功。
6. GitHub Actions release workflow 成功。
7. npm latest 解析到 `0.17.3`。
8. `bunx @zonease/aiworker-cli@0.17.3 --version` 报告 `aiworker/0.17.3`。
9. GitHub Release `v0.17.3` 存在且含四个平台 binary tarballs 和四个 matching
   `.sha256` checksum assets。
10. Published-package smoke 证明已发布 CLI 可启动 Host Web/API、bootstrap
    official HR/QA Soul Apps，并调用 HR/QA mounted actions。
