# BUG-117 Worker Web build chunk warning

- **status**: completed
- **priority**: P0
- **owner**: codex
- **createdAt**: 2026-05-13 15:41
- **plan**: PLAN-296
- **relatesTo**: apps/web, packages/component, packages/shared

## Description

Worker Web production build emits Vite's chunk-size warning because the primary
JavaScript bundle is above the default 500 kB limit. The fix should reduce the
actual initial bundle size instead of raising the warning threshold.

Acceptance criteria:

- The largest JavaScript chunk produced by `bun run --filter '@zonease/aiworker-web' build` is below Vite's 500 kB warning threshold.
- HR specialized workbench and markdown preview code load only when needed.
- Worker Web does not import the `@zonease/aiworker-shared` top-level barrel for runtime-only workbench catalog data.
- Existing Worker Web behavior and mounted surface smoke remain passing.

## ActiveForm

Reducing Worker Web initial JavaScript by splitting conditional HR/markdown
surfaces and avoiding heavy shared barrel runtime imports.
