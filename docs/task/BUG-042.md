# BUG-042 `aiworker up --dry-run` prints `NaN` for omitted port

- **status**: pending
- **priority**: P3
- **owner**: unassigned
- **createdAt**: 2026-05-02 19:51
- **discoveredAt**: 2026-05-02 19:49

## Observed Behavior

During the published `@zonease/aiworker-cli@0.5.0` smoke test, `aiworker up --soul developer --dry-run --no-open --no-serve-web` completed successfully but printed:

```text
port         : NaN
```

This only affects dry-run display output when `--port` is omitted.

## Expected Behavior

Dry-run output should show the effective environment/default port or an explicit placeholder such as `(env/default)`, never `NaN`.

## Reproduction

```bash
bunx --bun --package @zonease/aiworker-cli@0.5.0 aiworker up --soul developer --dry-run --no-open --no-serve-web
```

## Acceptance Criteria

1. `aiworker up --dry-run` without `--port` does not print `NaN`.
2. Existing `up` dry-run tests cover omitted port and explicit port output.
3. No serve behavior changes.
