# BUG-112 Worker list item status should be trailing-only

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-12 02:07
- **plan**: PLAN-270
- **relatesTo**: apps/web

## Background

Worker list items still show the status dot beside the worker name and render a trailing
`Soul + status` label. After grouping workers by Soul, the repeated Soul/status text inside
each item is redundant.

## Goal

Move the status dot to the trailing side of each worker list item and remove the redundant
Soul/status label from the item body.

## Acceptance Criteria

- Worker list item main text contains only the worker name.
- The status dot is rendered in the trailing column of the item.
- The former `Soul + Active` item label is not rendered.
- Worker selection and Soul group collapse/expand behavior remain unchanged.
- Tests and browser verification cover the item layout semantics.
