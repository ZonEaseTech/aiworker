# BUG-088 Worker Admin Chat renders the final assistant message twice

## Observed Behavior

Worker Admin Chat can render the final assistant reply twice: once from the
persisted message list and once from the local streaming preview. The visible
symptom is that the last assistant bubble appears again without persisted
message metadata after the turn has finished.

The current chat surface also uses a full near-black message field. After the
REFACTOR-017 Cohere visual refresh, this makes normal empty chat space read as
an oversized dark card instead of a restrained admin canvas.

## Expected Behavior

1. While a turn is streaming, the operator sees one live assistant preview.
2. After the assistant reply is persisted and the message query refreshes, the
   streaming preview no longer renders a duplicate of the same final text.
3. The Chat panel background uses the Cohere admin surface language: white or
   soft-stone canvas for the shell, deep green only for assistant message
   content or compact product/status surfaces.

## Investigation

- `apps/web/src/worker/features/chat/chat-panel.tsx` keeps `streaming` state
  after `orchestrator.finished`; `onDone` only sets `done: true` and invalidates
  messages.
- The persisted transcript is rendered from `useMessages(activeId)`, and the
  streaming preview is rendered independently whenever `streaming.text.length >
  0`.
- Once invalidation returns the persisted assistant message, both render paths
  can display the same final content.
- Backend `orchestrator.text` remains append-only per BUG-052/BUG-053; this
  issue is in the Worker Admin consumer layer, not the executor adapter or SSE
  event contract.

## Proposal

1. Track enough local turn context in the Chat panel to determine whether the
   current streaming preview has already appeared in the refreshed persisted
   messages.
2. Hide the streaming preview only after the persisted message list contains
   the final assistant content for that turn, preserving the live preview while
   the message query is still stale.
3. Add a focused Worker Admin Chat regression test for the
   persisted-message-plus-streaming-preview case.
4. Adjust only Chat panel classes so the message area uses a soft admin canvas,
   while assistant bubbles keep deep green and user bubbles remain white.
