# BUG-121 CLI self-updater cannot prove global package bundle source

- **status**: in_progress
- **priority**: P0
- **owner**: codex

- **claimedAt**: 2026-05-15 15:44
- **plan**: PLAN-329
- **relatesTo**: FEAT-086, REL-035, REL-036, v0.15.1

## 背景

用户在 `@zonease/aiworker-cli@0.15.0` 上执行 `aiworker upgrade` 时，
CLI 能解析 npm latest `0.15.1`，但安装源被判定为 `unknown`：

```json
{
  "source": {
    "canAutoUpgrade": false,
    "kind": "unknown",
    "reason": "installation source could not be proven"
  },
  "status": "source_unknown"
}
```

本机复现显示 `aiworker` 的 shim 位于 `/Users/ben/.bun/bin/aiworker`，但
shim 会 `exec bun .../node_modules/@zonease/aiworker-cli/aiworker-bun.js`。
运行时 `process.argv[1]` 已不再是 global bin shim，而是 package 内的 bundled
entrypoint。现有 detector 只覆盖 bin shim 路径，未覆盖 npm/Bun global package
root 下的真实 bundle 路径。

## 范围

- 修复 CLI updater install-source detection，让 npm global 与 Bun global package
  bundle 路径可被识别为可自动升级来源。
- 增加真实运行形态的 regression tests。
- 将 CLI patch version bump 到 `0.15.2` 并发布 patch release。
- 验证本地 focused tests、bundle、dist smoke、npm latest、`bunx` 和 published
  package smoke。

## 非范围

- 不改写已发布的 `0.15.0` / `0.15.1` npm package 或 GitHub tags。
- 不改变 source checkout、ephemeral `npx` / `bunx` 或 GitHub tarball 的安全策略。
- 不处理无关的 `FEAT-087 / PLAN-328` profile-ledger 工作区改动。

## 验收标准

1. `detectInstallSource` 能把 Bun global package bundle 路径识别为
   `bun-global`。
2. `detectInstallSource` 能把 npm global `lib/node_modules` package bundle 路径
   识别为 `npm-global`。
3. Source checkout、ephemeral cache、GitHub tarball 原有判定不回退。
4. 本地 focused updater tests、CLI tests、bundle 与 dist smoke 通过。
5. `@zonease/aiworker-cli@0.15.2` 发布成功，npm latest 指向 `0.15.2`。
6. 发布包 smoke 证明后续安装的 `aiworker upgrade --check` 能看到 package-manager
   source 而不是 `source_unknown`。
