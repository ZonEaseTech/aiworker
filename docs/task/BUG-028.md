# BUG-028 Web UI CSS bundle misses Tailwind utilities

- **status**: completed
- **priority**: P1
- **owner**: Codex
- **createdAt**: 2026-04-28 18:56
- **discoveredAt**: 2026-04-28 18:56
- **releaseTarget**: `@zonease/aiworker-cli@0.4.4`

## Description

The 0.4.3 fleet Web UI at the test-server public `/admin/` route renders as an
unstyled application even though the static asset route is now available.

Observed behavior:

1. Test-server gateway serves `/admin/assets/index-BPew1ixe.css` with HTTP 200.
2. The packaged fleet CSS under the global `@zonease/aiworker-cli` install is
   only 6111 bytes.
3. The packaged fleet CSS does not contain representative utilities such as
   `.flex` or `.bg-background`.
4. Local build output has the same shape: both `apps/web/dist/fleet` and
   `apps/web/dist/worker` emit a 6111-byte CSS file.
5. Searching the local CSS bundle for representative app classes such as
   `.flex`, `.min-h-screen`, `.rounded-md`, `.p-6`, `.border-r`,
   `.bg-background`, or `.text-foreground` returns no matches.
6. The Web source uses those utilities heavily in fleet, worker, and shared UI
   components, including `apps/web/src/fleet/routes/__root.tsx` and
   `apps/web/src/shared/components/ui/button-variants.ts`.

Root cause candidate:

- `apps/web/vite.config.ts` builds production bundles with
  `root: apps/web/{fleet,worker}`.
- The HTML entry then imports application code outside that root via
  `../src/{fleet,worker}/main.tsx`.
- `apps/web/src/shared/styles/globals.css` imports Tailwind with
  `@import 'tailwindcss';` but does not explicitly point Tailwind at
  `apps/web/src`.
- Tailwind v4 automatic source detection appears to scan the bundle root and
  misses the external `src` tree, so it emits base/theme CSS without app
  utility selectors.

## Acceptance Criteria

1. Rebuilding the Web bundles emits representative Tailwind utility selectors
   for both fleet and worker outputs.
2. `https://aiw.jbcnet.co.jp/admin/` renders with the intended fleet Web UI
   layout, spacing, colors, and component styling after basic auth.
3. Add a regression check that fails when the Web CSS bundle lacks critical
   generated utilities used by the app shell and shared UI components.
4. Keep `/admin/assets/*.css` served successfully through the gateway and Caddy
   ingress.
5. Verify the CLI publish packaging copies the corrected Web CSS into
   `@zonease/aiworker-cli/web/{fleet,worker}`.
