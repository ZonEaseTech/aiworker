## Background

The selected-session route still exposes duplicated or misplaced controls:

- The chat header contains a repeated “Back to worker” action while the left
  workspace rail already owns that navigation.
- The right session drawer owns its own refresh/settings/collapse controls,
  creating another command cluster disconnected from the main header.
- The drawer collapse state still leaves a small restore rail, so the drawer
  does not feel like a proper header-controlled sidebar.
- Several right drawer title rows can wrap or misalign icons in a narrow panel.
- Existing motion is present but not visible enough on the primary drawer and
  interaction surfaces.

## Goal

Make the selected-session route feel like one coherent workbench: the main
header owns global actions, the right drawer is toggled by a sidebar icon next
to settings, red-marked duplicate controls are removed, right drawer headings
stay aligned, and primary interactions have more perceptible transitions.

## Acceptance Criteria

- The selected-session chat header no longer shows the “Back to worker” button.
- The right session drawer no longer shows refresh/settings/collapse buttons in
  its own header.
- A sidebar icon button appears immediately to the right of the session header
  settings button.
- The sidebar icon button uses active state to open the right drawer and inactive
  state to collapse it.
- The collapsed drawer does not leave a clickable restore sliver.
- Right drawer title rows keep icons and labels aligned without awkward wrapping.
- Drawer open/close and primary interactive surfaces have smoother visible
  transitions.
