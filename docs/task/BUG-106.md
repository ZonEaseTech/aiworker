# BUG-106 Workspace create-session route lacks worker return action

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-11 20:45
- **plan**: PLAN-264
- **relatesTo**: apps/web

## 背景

移除 session 详情态里多余的“返回 worker”按钮后，workspace route 在未选中 session
的 create-session 状态也失去了回到当前 worker page 的入口。

## 目标

在未选中 session 的 workspace route 中恢复返回当前 worker page 的动作，同时保持
session 详情态只显示“返回工作区”。

## 验收标准

- `/workers/:workerId/workspaces/:workspaceId` 侧栏 context card 显示“返回 worker”。
- 点击后进入 `/workers/:workerId`。
- `/workers/:workerId/workspaces/:workspaceId/sessions/:sessionId` 不显示“返回 worker”。
- 更新 i18n、测试、浏览器验证和 code-review-graph 审查。
