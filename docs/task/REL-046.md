# REL-046 发布 aiworker CLI 0.18.0

- **status**: in_progress
- **priority**: P0
- **owner**: codex
- **createdAt**: 2026-05-19
- **claimedAt**: 2026-05-19
- **plan**: PLAN-366
- **relatesTo**: FEAT-098, PLAN-365, 9bfce75a, v0.17.6

## 背景

`v0.17.6` 是当前 npm latest 与 GitHub latest release。本轮已完成
`FEAT-098 / PLAN-365`，将 CLI 默认命令面收敛为 compact operator surface，
新增 `daemon restart`，并让 `aiworker update` 默认执行安全更新动作且自动重启
同一 `AIWORKER_HOME` 下的 managed daemon。

这些是面向 operator 的 CLI 行为与发现面变化，按 minor release 发布为 `0.18.0`。

## 范围

- 将 CLI package version 从 `0.17.6` bump 到 `0.18.0`。
- 运行本地 release gates，覆盖 full check/test/build、dist package、pack dry-run、
  dist release smoke 与 code-review-graph。
- 提交 release prep commit。
- 推送功能 commit、release prep commit 与 annotated tag `v0.18.0`。
- 监控 tag-triggered GitHub Actions release workflow。
- 验证 npm latest、显式 `bunx` 版本、GitHub Release assets 与
  published-package smoke。
- 更新本任务、`PLAN-366`、索引文件与 `docs/changelog.md` 的 release evidence。

## 非范围

- 不继续扩大 CLI command IA 到删除命令。
- 不改变 Host/Soul protocol、Soul App manifests 或 app domain semantics。
- 不重写既有 release workflow。
- 不处理未跟踪 `.superpowers/` 目录。

## 验收标准

1. 本地 release gate 全部通过。
2. `apps/cli/package.json` 与 `apps/cli/dist/package.json` 均报告 `0.18.0`。
3. `npm pack --dry-run --json` 证明 Worker Web、official HR/QA app resources
   与 CLI dist 进入发布包。
4. `smoke:dist-release` 证明 dist CLI 能启动 Host Web/API、bootstrap official
   HR/QA Soul Apps，并成功调用 HR/QA mounted actions。
5. `main` 与 `v0.18.0` 推送成功。
6. GitHub Actions release workflow 成功。
7. npm latest 解析到 `0.18.0`。
8. `bunx @zonease/aiworker-cli@0.18.0 --version` 报告 `aiworker/0.18.0`。
9. GitHub Release `v0.18.0` 存在且含四个平台 binary tarballs 和四个 matching
   `.sha256` checksum assets。
10. Published-package smoke 证明已发布 CLI 可启动 Host Web/API、bootstrap
    official HR/QA Soul Apps，并调用 HR/QA mounted actions。
