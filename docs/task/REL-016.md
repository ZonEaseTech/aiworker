## 描述

发布 `@zonease/aiworker-cli@0.9.0`，作为 `0.8.0` 之后的 minor release，交付 QA-006（0.8.0 published end-to-end debug campaign）登记的 Brain Governance Kernel retained defects，通过 PLAN-116 / PLAN-117 / PLAN-118 / PLAN-119 / PLAN-120 收口 truthfulness、admission governance、Codex parity、operator trust / safety 与 CLI onboarding polish。

本次发版包含：

- `PLAN-116` Truthfulness contract for orchestrator decision events and brain status surface。覆盖 `BUG-066` / `BUG-067`：decision event schema v2、observe-only / enforced mode truth table、LLM fallback raw output 脱敏留证、brain status `decisionPipeline` summary。
- `PLAN-117` Admission governance bridge and bypass guardrail。覆盖 `BUG-068` / `BUG-074`：正式 `aiworker brain admission propose` 入口、init 模板 Brain admission 指引、engine-native memory bypass suspected event / Worker Admin hint。
- `PLAN-118` Codex continuity and tool-call parity。覆盖 `BUG-069` / `BUG-070`：同 `chat-id` Codex conversation continuity、当前 Codex app-server tool/function/command frames 归一化。
- `PLAN-119` Init secret handling and executor doctor status truthfulness。覆盖 `BUG-071` / `BUG-072`：doctor surfaced warning rubric 统一、init 默认 token file + masked stdout、`--show-token` 显式明文输出闸门。
- `PLAN-120` CLI onboarding polish for command groups and executor hints。覆盖 `BUG-073` / `TODO-026` / `BUG-051`：group-level help、unknown command 语义、executor recommendation advisory-only 文案、`executor mcp add --arg -y` 支持。

`TODO-027` 已作为发布后 Governance Kernel regression harness 入口保留为 pending，不纳入本次 release blocker。
