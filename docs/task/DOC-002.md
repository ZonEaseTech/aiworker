## 描述

把 code-review-graph 在本仓库的安装状态、推荐命令和可用 MCP 工作流沉淀为项目级约定，方便日常代码审查、影响半径分析和架构探索稳定复用。

## 验收标准

1. 仓库提供统一的 `bun run crg:*` 脚本，避免本机 `code-review-graph` PATH 版本和 MCP `uvx` 版本漂移。
2. `AGENTS.md` 记录 code-review-graph 的推荐使用方式、稳定 MCP 工具集和当前需规避的不稳定端点。
3. 本仓库注册进 code-review-graph multi-repo registry，方便跨仓库搜索时按 repo 发现。
4. `crg:status`、`crg:update`、`crg:review` 至少完成一次聚焦验证。
5. 不提交 `.code-review-graph/graph.db` 等本地索引产物。
