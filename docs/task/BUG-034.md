# BUG-034 Web smoke-e2e imports removed gateway package path

## Description

The local Web/gateway protocol smoke script is stale after the gateway package
move from `apps/gateway` to `packages/gateway`.

Observed behavior during `QA-001`:

1. Running `PATH="$HOME/.bun/bin:$PATH" bun apps/web/scripts/smoke-e2e.ts`
   exits 1 before starting its gateway smoke.
2. Bun reports:
   `Cannot find module '../../gateway/src/index' from 'apps/web/scripts/smoke-e2e.ts'`.
3. The repository layout has `packages/gateway`, not `apps/gateway`, so the
   script's relative import is no longer valid.
4. The wrapper log is stored at
   `/home/ben/.codex/memories/aiworker-qa001-evidence/web-smoke-e2e-2050.log`.

Expected behavior:

- `apps/web/scripts/smoke-e2e.ts` should import the current gateway module and
  run the loopback gateway protocol smoke, or the obsolete script should be
  removed/replaced by the maintained package-level smoke.

## Acceptance Criteria

1. `PATH="$HOME/.bun/bin:$PATH" bun apps/web/scripts/smoke-e2e.ts` exits 0.
2. The script starts a temporary loopback gateway, verifies `workers.list`,
   `system.presence`, and offline `chat.send -> node_offline`, then stops the
   gateway and removes its temporary fleet DB directory.
3. The import path is resilient to the current monorepo layout and does not
   reintroduce `apps/gateway` assumptions.
4. Add or update a package script or CI-quality note if this smoke is expected
   to remain a supported release check.

## ActiveForm
