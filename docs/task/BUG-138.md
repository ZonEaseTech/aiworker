## Background

After `v0.18.2`, the HR People Workbench right panel still feels visually split:
Recent Sessions reads like a separate card, the composer controls sit as a
different surface, the add-file icon button is not well integrated with the
action bar, and the proposal type control is still a native `<select>` even
though `packages/component` already provides a Radix-backed `Select`.

The user wants the right panel to stay in the current design language and to
prefer shared component primitives where they exist.

## Scope

- Make the HR profile tools panel read as one continuous surface.
- Keep Recent Sessions compact at the top and visually connected to the
  composer.
- Replace the native proposal type selector with the shared
  `@zonease/aiworker-component` `Select`.
- Refine the add-file icon button and file count affordance inside the bottom
  action bar.
- Keep the send action as an icon-only submit button.
- Update focused Worker Web tests.

## Non-goals

- Do not change Host/Soul protocol semantics or session creation behavior.
- Do not change profile review promotion semantics.
- Do not extract a new component library abstraction unless a reusable
  app-agnostic primitive gap becomes unavoidable.
- Do not touch unrelated local changes such as `apps/web/public/favicon.svg`.

## Acceptance

1. The right panel uses a single visual container instead of two separated card
   surfaces.
2. Add-file, proposal type and send controls align as one action bar.
3. Proposal type uses the shared `Select` primitive from
   `packages/component`.
4. Existing multi-file attachment and profile draft session behavior remains
   intact.
5. Focused Web tests and visible UI verification pass.
