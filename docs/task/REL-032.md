## Context

`0.12.2` is a patch release for the executor non-interference boundary after
REFACTOR-026.

The release is needed because the previous published package still had default
paths where AIWorker could interfere with external executor runtime behavior:
native executor watchdogs, default approval overrides, task executor reuse for
control-plane LLM calls, aborting dead-loop heuristics, and non-durable Chat
failure visibility.

## Residual Risk

- This patch does not claim executor sandboxing or permission isolation under
  unmanaged ambient authority. External executor runtime still owns native
  approval, sandbox, session, and tool-loop semantics.
- Operators that want managed watchdog behavior must explicitly configure
  executor `timeoutMs` or `PROCESS_STALL_TIMEOUT_MS`.
