## 背景

`@zonease/aiworker-cli@0.12.2` 是当前 npm latest 与最新 GitHub Release。
`v0.12.2..HEAD` 已包含 FEAT-082 的 npm preview release readiness 闭环：

- CLI dist package 携带 Worker Web static、worker DB migrations 与官方 HR/QA
  Soul App release resources。
- dist/npm 运行时通过 package-local resource locator 启动 Host Web/API。
- `app bootstrap official` 能在 dist 环境安装并启用随 CLI 打包的 official
  HR/QA Soul Apps。
- `smoke:dist-release` 覆盖 daemon、Host Web、app catalog、official app
  bootstrap、app list、Soul list 与 HR template projection。

这批变更让外部用户可通过 `bunx` / `npx @zonease/aiworker-cli` 看到新的
preview 产品路径，不应作为 patch 发布；本次按 pre-1.0 minor release 发布
`0.13.0`。

## 范围

- 将 `apps/cli/package.json` 更新到 `0.13.0`。
- 运行本地 source/build gate。
- 验证 CLI dist package 与 npm pack 内容。
- 验证 dist release smoke。
- 提交 release prep commit。
- 推送 `main` 与 annotated tag `v0.13.0`。
- 监控 tag-triggered GitHub Actions release workflow。
- 验证 npm latest、显式 package smoke、GitHub Release assets。
- 运行或替代记录 published-package compact governance harness。

## 非范围

- 不发布 `@zonease/aiworker-soul-app-sdk` 或
  `@zonease/aiworker-soul-app-runtime` 独立 npm 包。
- 不声明第三方 Soul App authoring 已可在 monorepo 外完整使用。
- 不声明 1.0 GA。
- 不实现 Host auth。
- 不新增 gateway/fleet、远程控制面、cloud marketplace 或 hosted service scope。

- 本次不发布 SDK/runtime npm packages；第三方 Soul App authoring 在 monorepo 外的
  独立可用性仍需后续单独任务验证。
