## Background

Worker Web exposed only the internal `--font-aiworker-*` variables and relied on
platform fallbacks. The expected design token shape is:

- `--font-display`: Nunito for display / heading surfaces.
- `--font-ui`: Inter for normal UI copy.
- `--font-mono`: JetBrains Mono for terms, constants, numbers, fixed tags, and
  button labels.

The app also lacked explicit self-hosted font loading and preload hints for
above-the-fold typography.

## Goal

Make the font scheme explicit, locally loaded, and consistently applied across
machine-readable UI surfaces.

## Acceptance Criteria

- `--font-display`, `--font-ui`, and `--font-mono` are defined in the Worker Web
  token layer.
- Existing aliases (`--serif`, `--sans`, `--mono`) resolve to the new token
  scheme.
- Nunito, Inter, and JetBrains Mono are self-hosted and preloaded from
  `index.html`.
- Buttons, tags, status pills, metadata, IDs, counts, fixed labels, and other
  machine-readable UI terms use the mono font.
