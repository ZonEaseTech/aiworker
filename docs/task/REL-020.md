## 描述

发布 `@zonease/aiworker-cli@0.9.4`，作为 `0.9.3` 之后的 patch release，
交付远端 fleet-hosted Worker Admin 与 OTP worker reconnect 修复。

本次发版包含：

- `BUG-079 / PLAN-136`：恢复 public Caddy `/w*` route，fleet 域名可以托管
  Worker Admin shell 与 gateway worker bridge。
- `BUG-080 / PLAN-137`：已批准 OTP worker 可以继续在 `/enroll-ws` 上用
  registered worker token 重连，不需要 operator Basic Auth。
- `BUG-081 / PLAN-138`：`/w/:workerId/api/worker/*` 改由 gateway 校验 worker
  bearer token；Caddy 不再对 `/w*` 做 Basic Auth，避免覆盖 Worker Admin 的
  `Authorization: Bearer <worker token>`。
