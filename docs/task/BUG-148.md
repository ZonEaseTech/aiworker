## Background

The shadcn migration introduced `@zonease/aiworker-ui` as the active shared UI
package, but the session composer still has multiple live implementations or
copies:

- `packages/ui/src/components/session-composer.tsx` is the shadcn-first shared
  implementation and currently has the most complete panel layout behavior.
- `apps/web/src/features/session/session-composer.tsx` is an app-local copy that
  is slightly stale compared with the shared UI package.
- `packages/component/src/patterns/session-composer.tsx` is legacy migration
  debt and must not be treated as the current source of truth.
- The HR Soul App already consumes `@zonease/aiworker-ui` but its wrapper does
  not provide image preview URLs, so attached images show as files instead of
  previewable images.

The session chat container has been heavily tuned and must remain out of scope
for this cleanup.

## Acceptance Criteria

1. HR profile composer image attachments render thumbnail preview affordances
   through the shared `@zonease/aiworker-ui` SessionComposer.
2. HR profile composer manages object URL cleanup for previewable image
   attachments.
3. Host Web session and workspace composer wrappers import the shared
   `@zonease/aiworker-ui` SessionComposer instead of the app-local copy.
4. The app-local duplicate composer file and tests are removed only after the
   shared UI tests cover the preserved behavior.
5. `WorkerSessionChat`, session timeline rendering, session view-model parsing,
   scroll pinning, detail drawer behavior and message flow rendering are not
   changed.
6. Focused HR/Web/UI tests, typecheck and UI governance checks pass or record
   explicit residual risk.

## Scope

- HR people workbench profile composer wrapper.
- Host Web composer wrapper imports for workspace/session submit surfaces.
- Shared UI SessionComposer tests for image preview and panel sizing behavior.
- Removal of duplicate app-local composer implementation if consumers are moved.
- PMA/changelog tracking for the consolidation.

## Non-Goals

- No changes to `WorkerSessionChat` behavior or layout.
- No changes to session timeline, event normalization or markdown rendering.
- No broad redesign of HR workbench columns.
- No migration of Host-specific session orchestration into `packages/ui`.
- No compatibility polishing inside legacy `packages/component`.

## Resolution

Consolidated active session composer consumers on
`@zonease/aiworker-ui/components/session-composer`.

- HR profile composer now creates preview URLs for image candidate materials,
  passes preview labels into the shared composer, and revokes object URLs on
  removal, submit-clear and unmount.
- Host Web workspace and session turn composer wrappers now import the shared
  UI component, types and paste/image helpers from `packages/ui`.
- The stale app-local composer implementation and duplicate test file under
  `apps/web/src/features/session/` were removed after preserving behavior in
  `packages/ui` tests.
- `WorkerSessionChat`, session timeline, session view-model and message-flow
  files were intentionally left untouched.
