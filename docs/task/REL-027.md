## 背景

`@zonease/aiworker-cli@0.10.2` 是当前 npm latest 与最新 GitHub Release。
`v0.10.2..HEAD` 已包含 Project Brain 文件布局收敛、worker env shortcuts、
gateway enrollment hints、README 用户定位与拓扑表达等 commits。

本次按 patch release 发布 `0.10.3`，并在发布后使用已发布 npm package 走
`aiworker-validate cli-release-local` compact harness。

## 范围

- 将 `apps/cli/package.json` 与 README latest 更新到 `0.10.3`。
- 运行本地 release gate。
- 构建并检查 CLI dist 产物版本。
- 执行 publish dry-run 到本机 npm auth boundary。
- 提交 release bump。
- 推送 `main` 与 annotated tag `v0.10.3`。
- 监控 tag-triggered GitHub Actions release workflow。
- 验证 npm latest、显式 package smoke、GitHub Release assets。
- 运行发布包 `cli-release-local` compact harness。

## 非范围

- 不修改运行时代码。
- 不重新设计 release workflow。
- 不做 fleet/gateway 远端验证，除非发布包 worker 验证暴露需要升级范围的问题。

## 验收标准

1. 本地 release gate 全部通过。
2. `main` 与 `v0.10.3` 推送成功。
3. GitHub Actions release workflow 成功。
4. npm latest 解析到 `0.10.3`。
5. `bunx @zonease/aiworker-cli@0.10.3 --version` 报告 `aiworker/0.10.3`。
6. GitHub Release `v0.10.3` 存在且含四个平台 binary assets。
7. 发布包 `cli-release-local` compact harness 通过，或记录明确 finding / blocker。
