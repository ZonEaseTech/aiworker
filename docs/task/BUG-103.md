# BUG-103 Settings 引擎操作按钮样式不统一

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-11 20:12
- **plan**: PLAN-261
- **relatesTo**: apps/web

## 背景

Settings dialog 的本地 CLI 引擎区块里，“测试”和“重新扫描”按钮使用了 `iconOnly`
触发的 `icon-btn` 样式，但两个按钮实际都带文字，视觉尺寸、字号和语义都与其他小型
action button 不一致。

## 目标

将这两个引擎操作按钮收敛为 settings 内统一的小号 action button。

## 验收标准

- “测试”和“重新扫描”使用同一套按钮 class。
- 两个按钮不再使用 `icon-btn`。
- 两个按钮都有一致的图标、字号、间距、圆角和 hover 风格。
- 原有测试与重新扫描行为保持不变。
- 更新测试、浏览器验证和 code-review-graph 审查。
