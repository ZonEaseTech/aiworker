## Description

Run a real Codex-backed HR native skill debug campaign. The campaign must start
from zero-profile HR workspaces, exercise every HR native skill through
multi-turn sessions, inspect generated artifacts and reviews, and verify whether
reviewed profile update proposals can be promoted into the accepted workspace
`README.md`.

The campaign should collect reproducible bugs and optimization items while
keeping mutable AIWorker state in a disposable debug root and preserving the
real user `HOME` / Codex login state.

## ActiveForm

Running a real Codex-backed HR native skills README closure debug campaign.

- **blocked by**: (none)
- **blocks**: HR native skill prompt and product-policy tuning.

## Acceptance Criteria

- At least three HR profiles are created from zero state in an isolated
  `AIWORKER_HOME`.
- Each profile runs all five HR native skills:
  `candidate-profile`, `evidence-screening`, `interview-brief`,
  `hiring-risk-review`, and `profile-update-proposal`.
- Every skill session has at least two turns.
- The campaign inspects generated artifacts, review records, workspace files,
  and final `README.md` content.
- At least two profiles attempt reviewed promotion into `README.md`.
- Reproducible bugs and optimization items are recorded as PMA tasks when found.
- The final report summarizes the matrix, evidence paths, fixes, verification
  and residual risks.

  real user Codex login preserved.

  both generated profile ledger git commits.

## Findings

- Fixed: profile ledger git operations followed a parent ignored repo instead
  of forcing a workspace-local git repository. Tracked by `BUG-126`.
- Fixed: CLI continuation turns lost capability metadata and could show
  `business-artifact` instead of the selected output kind. Tracked by
  `BUG-127`.
- Fixed: HR product promotion could write proposal-shaped artifact markdown
  into accepted `README.md`; promotion now extracts an explicit
  `aiworker-profile-readme` draft. Tracked by `BUG-128`.
- Open bug: a failed Codex turn can leave files under `artifacts/` without
  registering them. Tracked by `BUG-129`.
- Open optimization: HR native skills need first-class artifact kinds beyond
  `person-profile` / `candidate-screen`. Tracked by `TODO-043`.
- Open optimization: external engines need capability prompt/review content,
  not only inaccessible `product/workflows/...` refs. Tracked by `TODO-044`.
