# BUG-013 `workers.info` / `workers.stop` 在 node-side dispatcher 显式 stub `method_not_implemented`

- **status**: pending
- **priority**: P2
- **owner**: (unassigned)
- **createdAt**: 2026-04-27 12:25
- **discovered**: 2026-04-27 11:00 — REFACTOR-004 e2e demo 跑 `aiworker fleet info <workerId>` 时发现，错误信息：
  ```
  workers info 失败: method_not_implemented: workers.info is not yet implemented on node side
  ```

## Description

`packages/core/src/worker/gateway-client/dispatcher.ts:143-149`：

```ts
case METHODS['workers.info'].method:
  // workers.info 暂不实现；S5 会在删 HTTP 路由时一并迁过来。
  this.replyError(id, 'method_not_implemented', `${method} is not yet implemented on node side`)
  break
case METHODS['workers.stop'].method:
  this.replyError(id, 'method_not_implemented', `${method} is not yet implemented on node side`)
  break
```

两个 method 在 worker (node) 侧 dispatcher 显式回 `method_not_implemented`。注释说"S5 会在删 HTTP 路由时一并迁过来"——PLAN-013 S5 已经下线了 HTTP 路由（dashboard REST 已删），但这两个 handler 没补上。

### 用户可见影响

- `aiworker fleet info <workerId>` 永远失败（operator 拿不到 worker 运行时元数据：config version、brain/executor/channel 计数、uptime、最近 N 条 audit 等）
- `aiworker fleet stop <workerId>` 永远失败（operator 没法远程下发停止指令；只能本机 SIGTERM 或 ssh）

REFACTOR-004 的 e2e demo（`aiworker chat` 链路）能跑通，因为 chat.send dispatcher 已实现。但 `fleet info` 这类常用 introspection 命令完全瘫痪。

### Acceptance criteria

1. `aiworker fleet info <workerId>` 返回结构化 JSON，至少含：
   - `workerId`、`displayName`
   - `configVersion`（来自 `worker_config.version`）
   - `runtime`：`{ brains: number, channels: number, executor: { engine, variant } }`
   - `uptimeSec`、`startedAt`
   - 可选 `recentAudit`：最近 5 条本地审计事件
2. `aiworker fleet stop <workerId>` 让 worker 进程优雅 shutdown（SIGTERM 自身 → close gateway WS → exit 0）。Operator 端立即收 `done`，gateway 收 `worker.offline`。
3. 实现位置：`packages/core/src/worker/gateway-client/dispatcher.ts` 内新增 `handleWorkersInfo` / `handleWorkersStop` private methods；handler 接口扩 `NodeHandlers`（`workersInfo?: () => Promise<...>` / `workersStop?: () => Promise<void>`）。
4. `apps/cli/src/commands/serve.ts::startGatewayNode` 注入两个 handler：
   - `workersInfo`: 读 `state.workerId` + `state.runtime` 元数据 + `worker_config.version` 拼 JSON
   - `workersStop`: 调 SIGTERM 自身（`process.kill(process.pid, 'SIGTERM')`）；优雅关 server 与 gateway-client
5. cli 命令 `apps/cli/src/aim/commands/workers.ts::runWorkersInfo` / `runWorkersStop` 已存在，无需改。
6. gateway 测试：`packages/gateway/test/dispatch.test.ts` 加两个 case 验证 forward → node 收到 → 回 ok response。
7. cli/0.2.x 发布前必须修。
