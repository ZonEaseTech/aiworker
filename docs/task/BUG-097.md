# BUG-097 Workspace route page structure differs from worker route

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-11 17:11
- **plan**: PLAN-255
- **relatesTo**: apps/web

## Background

`workers/[worker_id]` uses an overview panel followed by a managed collection
section. `workspaces/[workspace_id]` instead showed a create-session form and a
single empty-state block, so the workspace page did not read like the same
management surface.

## Goal

Make the workspace route follow the same page rhythm as the worker route:
overview first, managed collection second.

## Acceptance Criteria

- Add a workspace overview panel that mirrors the worker overview pattern.
- Move sessions into a managed collection section with toolbar and grid cards.
- Keep the create-session form available on the workspace route.
- Add dedicated workspace session card/identity components instead of folding
  this into worker card semantics.
- Update tests and run focused Web validation plus code-review-graph.
