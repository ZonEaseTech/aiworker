# BUG-094 Worker Web worker list rail height is constrained

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-11 16:24
- **plan**: PLAN-252
- **relatesTo**: apps/web

## Background

Worker Web used a hard `188px` max height for the worker list rail while the
worker list panel itself was `flex: 0 0 auto`. After removing the redundant
execution readiness card, the worker list still rendered as a short card and
left unused space in the sidebar.

## Goal

Let the worker list section own the remaining sidebar height and make the list
itself the scroll container.

## Acceptance Criteria

- Remove the fixed worker list max-height.
- Let the worker list panel flex into available rail height.
- Keep the worker list header fixed while rows scroll.
- Keep footer/settings controls reachable.
- Run focused Web validation and code-review-graph before closure.
