## Background

Manual mobile verification showed the session route was treated as passing
because Playwright boxes stayed inside the 390px viewport. The actual visual
result was still unacceptable: the full sidebar, chat surface, and artifact
rail were stacked into one viewport, leaving crowded and partially obscured
content.

## Goal

Repair the mobile session route so the workspace navigation is compact, the
chat surface keeps usable height, and the artifact rail behaves as a bounded
bottom preview instead of competing for the whole viewport.

## Acceptance Criteria

- Session mobile sidebar hides nonessential brand/readiness/list/footer content.
- Session mobile context card keeps only return actions and workspace context.
- Chat header can wrap controls without covering title or log content.
- Artifact rail has bounded mobile height and does not crush the chat surface.
- 390px Playwright MCP snapshot is used as visual evidence, not only overflow
  evidence.
