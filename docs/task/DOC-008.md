## Background

User clarified that the Open Design screenshots and source should not lead to a
literal Web copy or another developer-centered worker surface. The intended
reboot is to borrow Open Design's product grammar while building AIWorker as a
vertical Soul workspace for team/org roles such as HR, PM, QA, DevOps, finance,
legal, and ops.

## Goal

Reset the repository's product guardrails so future implementation starts from:

```text
Soul + domain system + capability template
  -> case
  -> engine run
  -> business artifact
  -> review
  -> durable org memory
```

Developer remains a supporting Soul rather than the default product center.

## Acceptance Criteria

- `GOALS.md` defines vertical Soul workspace as the north star.
- `docs/architecture.md` maps the target architecture to Soul, domain system,
  capability template, case, artifact, review, and durable org memory.
- `AGENTS.md` gives future agents explicit anti-drift rules against
  developer-first, engine-platform, and Open Design shell-copy directions.
- `README.md` presents the new product positioning and roadmap.
- Documentation records that Open Design is a product-language reference, not a
  visual/brand/domain copy target.
