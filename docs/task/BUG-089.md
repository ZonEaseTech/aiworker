# BUG-089 Worker Config save bar floats and exceeds content width

- **status**: completed
- **priority**: P2
- **owner**: local
- **createdAt**: 2026-05-07 17:46
- **claimedAt**: 2026-05-07 17:46
- **completedAt**: 2026-05-07 17:47
- **plan**:
- **relatesTo**: REFACTOR-017

## Problem

The Worker Admin Configuration page renders its save controls as a sticky
bottom bar inside the page scroll container. The bar also uses negative
horizontal margins, so it exceeds the centered content width on desktop.

## Impact

- The save controls appear detached from the form while scrolling.
- The bar can become wider than the rest of the page content.
- The issue is visible on the Worker Admin Configuration page after the Web UI
  redesign.

## Expected

The save controls should stay within the normal form flow and respect the same
content width as the rest of the page.

## Acceptance Criteria

1. The Configuration save controls no longer use a sticky bottom bar.
2. The save controls no longer exceed the page content width.
3. The focused Web build passes.

## Notes

- 2026-05-07 17:46: Opened from UI inspection. The shell-level scroll container
  is intentional; the page-level sticky save bar is the source of the floating
  behavior.

## Resolution

- Removed the Configuration form's bottom padding that only supported the
  sticky save bar.
- Replaced the sticky bottom save bar with an in-flow action panel that respects
  the page content width.

## Validation

- `bun run --filter '@zonease/aiworker-web' build` passed.
