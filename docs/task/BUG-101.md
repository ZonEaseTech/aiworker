# BUG-101 工作区会话头部缺少新建会话动作

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-11 18:09
- **plan**: PLAN-259
- **relatesTo**: apps/web

## 背景

Workspace 侧栏的“工作区会话”区块头部右侧显示的是会话数量。这个位置的真实意图应与
“其他工作区”中的“新建工作区”一致，是一个快捷动作：从当前 session 返回当前
workspace 的创建会话入口。

## 目标

把“工作区会话”头部右侧从数量徽标改为“新建会话”动作。

## 验收标准

- “工作区会话”头部右侧显示“新建会话”按钮。
- 点击该按钮导航到当前 workspace 的无 session 路由。
- 无 session 路由显示 create-session composer。
- 更新测试、浏览器验证和 code-review-graph 审查。
