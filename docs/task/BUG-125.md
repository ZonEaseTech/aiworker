## Background

FEAT-093 moved HR profile sources, proposed changes, guardrails and sessions
into a right tools rail/drawer while making the accepted README the center
Reading Room. Manual UI review after the release found four regressions:

1. HR drawer expand/collapse has no visible motion.
2. When no workspace/profile is selected, the HR workbench still forces the
   second and third columns instead of showing an empty selection prompt.
3. The collapsed right icon rail is horizontally off-center.
4. `Profile Actions` still reads as a cockpit rather than a simple profile
   workbench.

## Goal

- Make HR profile selection explicit before showing profile detail/tools.
- Add visible, token-aligned drawer motion for HR profile list and tools rail.
- Center the collapsed right rail icons.
- Reframe the expanded right drawer as a focused next-profile workbench.

## Non-Goals

- Do not change Host/Soul protocol semantics.
- Do not make Host interpret HR profile content.
- Do not remove review-gated profile promotion.
- Do not broaden this into a new HR artifact model.

## Acceptance Criteria

1. Entering the HR worker home without an explicit workspace selection shows a
   clear empty/select state and does not render profile details or tools rail.
2. Selecting a profile/workspace opens the Reading Room and enables the compact
   right workbench.
3. HR profile-list and tools drawer toggles animate width/content transitions.
4. The collapsed right rail icon buttons are visually centered.
5. The expanded right drawer prioritizes one next profile action/composer over
   dashboard-style inventories.
6. Focused Web tests and browser smoke cover the changed visible behavior.
