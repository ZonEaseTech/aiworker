# BUG-096 Worker workspace cards render as a single-column list

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-11 16:59
- **plan**: PLAN-254
- **relatesTo**: apps/web

## Background

The worker-managed workspace area rendered card-shaped workspace entries inside
`design-grid-list`, which forced the container into a single-column list. This
made card UI behave like a list item without a dedicated list-item component.

## Goal

Use a real grid for workspace cards. Do not introduce a list toggle unless it
has its own list-item component.

## Acceptance Criteria

- Worker workspace card view uses a responsive grid.
- Remove the single-column `design-grid-list` contract from this surface.
- Rename the local workspace card component to match workspace semantics.
- Add a focused regression check that the workspace container uses grid-card
  layout, not list-card layout.
- Run focused Web validation and code-review-graph before closure.
