## Background

The latest `lint` and `release` GitHub Actions runs completed successfully, but
GitHub emitted Node.js 20 action runtime deprecation annotations:

- `lint.yml`: `actions/setup-node@v4`
- `release.yml`: `actions/setup-node@v4`
- `release.yml`: `softprops/action-gh-release@v2`

The workflows already install project Node.js 24 with `node-version: '24'`.
The warning is about the JavaScript action runtime declared by those actions,
not the Node.js version used by AIWorker build scripts.

## Scope

- Update `actions/setup-node@v4` to `actions/setup-node@v5` in both workflows.
- Update `softprops/action-gh-release@v2` to `softprops/action-gh-release@v3`
  in the release workflow.
- Preserve `runs-on: ubuntu-latest`, `NODE_OPTIONS=--max-old-space-size=1024`,
  `node-version: '24'`, npm publish behavior, binary packaging, and release
  asset names.
- Record verification and close the PMA trail.

## Acceptance Criteria

1. `.github/workflows/lint.yml` no longer references `actions/setup-node@v4`.
2. `.github/workflows/release.yml` no longer references `actions/setup-node@v4`
   or `softprops/action-gh-release@v2`.
3. The workflows reference `actions/setup-node@v5` and
   `softprops/action-gh-release@v3`.
4. The workflows still use Node.js 24 for project build steps and keep the
   release-stabilizing Node heap setting.
5. Focused verification passes locally.
