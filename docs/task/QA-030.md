## Goal

Validate the corrected session runtime from a clean local AIWorker home and a
real browser:

1. Open Worker Web and enter an existing Soul workspace session.
2. Send a turn through the configured external engine.
3. Confirm the operator message appears immediately.
4. Confirm structured status/tool/text/usage events appear in the session
   timeline.
5. Confirm stderr is not the primary view for a successful turn.
6. Confirm text-only continuation succeeds.
7. Confirm an artifact-producing turn indexes an artifact when the engine
   writes one.
8. Confirm Settings engine scan/test still works.

## Acceptance Criteria

- Focused core/API/Web gates pass.
- Browser validation covers desktop and narrow viewport scroll behavior.
- Local daemon preview URL is provided.
- code-review-graph review is completed after code changes.

  Codex CLI.
