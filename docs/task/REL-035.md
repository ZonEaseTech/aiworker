# REL-035 发布 aiworker CLI 0.15.0

- **status**: in_progress
- **priority**: P1
- **owner**: codex
- **createdAt**: 2026-05-15 13:37
- **claimedAt**: 2026-05-15 13:37
- **plan**: PLAN-326
- **relatesTo**: FEAT-086, PLAN-325, v0.14.0

## 背景

`@zonease/aiworker-cli@0.14.0` 是当前 npm latest，且本地与远端均未使用
`v0.15.0` tag。`main` 已合入 FEAT-086 / PLAN-325，新增 top-level
`aiworker update` / `aiworker upgrade` self-updater、GitHub bundle checksum
校验和完整 bundle replacement。

该能力是用户可见的 CLI/Host distribution 能力，适合作为 `0.x` minor release
发布为 `0.15.0`。

## 范围

- 将 CLI package version 从 `0.14.0` bump 到 `0.15.0`。
- 补齐 GitHub release bundle `.sha256` 资产生成和上传。
- 运行本地 source/build/dist/pack/smoke release gates。
- 提交 release prep commit。
- 推送 `main` 与 annotated tag `v0.15.0`。
- 监控 tag-triggered GitHub Actions release workflow。
- 验证 npm latest、显式 package smoke、GitHub Release tarball/checksum assets
  与 published-package preview smoke。
- 更新本任务、`PLAN-326`、索引文件与 `docs/changelog.md` 的 release evidence。

## 非范围

- 不发布 `@zonease/aiworker-soul-app-sdk` 或
  `@zonease/aiworker-soul-app-runtime` 独立 npm 包。
- 不声明 1.0 GA。
- 不新增 Host auth、cloud marketplace、gateway/fleet 或远程控制面 scope。
- 不重写 `0.14.0` release tag 或 npm package。

## 验收标准

1. 本地 release gate 全部通过。
2. `apps/cli/package.json` 与 `apps/cli/dist/package.json` 均报告 `0.15.0`。
3. `npm pack --dry-run --json` 证明 CLI shims、Worker Web static、worker
   migrations 与官方 HR/QA app release resources 进入发布包。
4. `smoke:dist-release` 证明 dist CLI 能启动 Host Web/API、bootstrap official
   HR/QA Soul Apps，并能发现 HR template。
5. `main` 与 `v0.15.0` 推送成功。
6. GitHub Actions release workflow 成功。
7. npm latest 解析到 `0.15.0`。
8. `bunx @zonease/aiworker-cli@0.15.0 --version` 报告 `aiworker/0.15.0`。
9. GitHub Release `v0.15.0` 存在且含四个平台 binary tarballs 和四个
   matching `.sha256` checksum assets。
10. Published-package smoke 证明已发布 CLI 的 Host/Soul App preview path 可用。
