# BUG-137 Host left panel toggle lacks active highlight

- **status**: completed
- **priority**: P1
- **owner**: codex
- **createdAt**: 2026-05-18
- **claimedAt**: 2026-05-18
- **plan**: PLAN-362
- **relatesTo**: apps/web, Worker Studio, Host shell

## 背景

用户反馈 Host 的 left panel toggle icon 在激活状态下没有像 HR toggle
一样高亮。该控件位于 Host shell topbar，属于 Host-owned 平台 shell
交互，不涉及 Soul App 领域语义。

## 调查记录

- HR People Workbench 的 profile list toggle 通过 `aria-pressed` 表示可见
  状态，因此会命中共享 `.icon-button[aria-pressed="true"]` active 样式。
- Host `HostTopBar` 的 left sidebar toggle 只有 label/title/click handler，
  没有暴露 pressed state，导致侧栏可见时不会出现 active highlight。
- 红测已复现：`worker-studio.test.tsx` 中 Host sidebar toggle 的
  `aria-pressed` 在修复前为 `null`，期望为 `true`。

## 验收标准

- Host left panel toggle 在侧栏可见时暴露 `aria-pressed="true"` 并获得
  共享 active icon button 样式。
- Host left panel toggle 在侧栏折叠后暴露 `aria-pressed="false"`。
- HR toggle 行为和样式不变。
- Focused Worker Studio test 覆盖该回归。
- Web typecheck/lint/build 与 browser smoke 通过。

  与 HR panel toggle 共用 active icon button 样式合同。
