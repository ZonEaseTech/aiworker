# BUG-111 Worker list should be grouped by Soul

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-12 01:59
- **plan**: PLAN-269
- **relatesTo**: apps/web

## Background

The Worker home rail currently renders workers as one flat list. Each item repeats the Soul
name, but operators cannot scan workers by vertical Soul category or collapse categories.

## Goal

Group the worker list by Soul and make each Soul category collapsible.

## Acceptance Criteria

- Worker list groups workers by `soulId` using localized Soul names.
- Each Soul group has a visible header with count text in the title.
- Each Soul group can collapse and expand without changing the selected worker.
- Worker item layout remains consistent with the existing rail visual system.
- Tests and browser verification cover the grouped/collapsible behavior.
