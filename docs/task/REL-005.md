## Description

发布 `@zonease/aiworker-cli@0.4.8`，作为 `0.4.7` 之后的 patch release。

本次发版包含 `0.4.7` 之后已合入 main 的改动：

- Fleet 同源托管 Worker UI：gateway 托管 `/w/:workerId/` worker bundle。
- Worker UI 在 fleet-hosted 模式下使用 same-origin gateway bridge 和 worker-scoped SSE。
- Gateway bridge 覆盖当前 Worker UI 使用的 REST 能力，并保持 fleet/worker 数据边界。
- Fleet UI worker 入口改为 `/w/:workerId/`，不再要求 worker 暴露 public `baseUrl`。

Release checklist:

1. 将 CLI package 版本从 `0.4.7` bump 到 `0.4.8`。
2. 跑完本地 release quality gates。
3. 构建 publish artifact，并确认 dist manifest 报告 `0.4.8`。
4. 通过现有 tag-triggered GitHub release workflow 发布。
5. 验证 npm `latest` 解析到 `0.4.8`，并验证已发布 CLI 版本。
