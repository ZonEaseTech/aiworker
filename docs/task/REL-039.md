## 验收标准

1. 本地 release gate 全部通过。
2. `apps/cli/package.json` 与 `apps/cli/dist/package.json` 均报告 `0.17.0`。
3. `npm pack --dry-run --json` 证明 HR Reading Room 相关 Web bundle 与官方
   HR/QA app resources 进入发布包。
4. `smoke:dist-release` 证明 dist CLI 能启动 Host Web/API、bootstrap official
   HR/QA Soul Apps，并成功调用 HR `create-people-profile` 与 QA
   `create-release-gate` mounted actions。
5. `main` 与 `v0.17.0` 推送成功。
6. GitHub Actions release workflow 成功。
7. npm latest 解析到 `0.17.0`。
8. `bunx @zonease/aiworker-cli@0.17.0 --version` 报告 `aiworker/0.17.0`。
9. GitHub Release `v0.17.0` 存在且含四个平台 binary tarballs 和四个 matching
   `.sha256` checksum assets。
10. Published-package smoke 证明已发布 CLI 可启动 Host Web/API、bootstrap
    official HR/QA Soul Apps，并访问 HR profile-first workbench surface。
