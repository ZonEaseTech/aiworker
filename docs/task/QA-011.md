## Scope

prove the positive Project Brain admission roundtrip invariant:

- `pending → approved → applied` transitions are reflected in
  `brain_admission_proposals.status` and `brain_admission_decisions`.
- The materializer writes the canonical memory file under
  `<projectScope>/.aiworker/memories/<topic>.md` and appends an index entry to
  `MEMORY.md`.
- `aiworker brain brief` projection picks up the applied memory.
- The pre-apply canonical memory boundary stays empty.
