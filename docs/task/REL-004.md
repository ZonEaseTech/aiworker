## Description

发布 `@zonease/aiworker-cli@0.4.7`，作为 `0.4.6` 之后的 patch release。

本次发版包含 `0.4.6` 之后已合入 main 的改动：

- `aiworker init` preflight / `--dry-run`，默认保留既有项目上下文和外部 agent 文件。
- Fleet Audit log 表格内部滚动修复。
- code-review-graph 项目级开发工作流接入。
- Gateway worker bridge MVP：node-side `workers.info` / `workers.stop` handler，以及
  `/w/:workerId/api/worker/info`、`GET/PUT /config` 的 allowlisted HTTP bridge。

本次不宣称完成 FEAT-040 / PLAN-042 的完整 Fleet-hosted Worker UI、SSE bridge 或全量
worker REST/proto 覆盖；这些继续由后续任务完成。

Release checklist:

1. 将 CLI package 版本从 `0.4.6` bump 到 `0.4.7`。
2. 跑完本地 release quality gates。
3. 构建 publish artifact，并确认 dist manifest 报告 `0.4.7`。
4. 通过现有 tag-triggered GitHub release workflow 发布。
5. 验证 npm `latest` 解析到 `0.4.7`，并验证已发布 CLI 版本。
