## Description

发布 `@zonease/aiworker-cli@0.4.10`，作为 `0.4.9` 之后的 patch release。

本次发版包含 `0.4.9` 之后已合入 main 的改动：

- `aiworker init` 的 Soul 选择流程修复：全新项目非交互初始化必须显式提供 `--soul`，并写入非 stub 的 persona、policy、toolsets 与 capability pack 草案。
- 项目级 engine cwd 修复：project scope 默认在项目根目录执行，同时保留 `.aiworker/AGENT.md`、`SOUL.md`、`USER.md`、`MEMORY.md` 与 `ROLLUP.md` 注入。
- Worker 决策管线 S1-S5：拆出 context composition，增加 capability registry、intent classifier、quality gate 和 quality gate learning proposal。
- 记录 Orchestrator control executor 与 task executor 解耦的后续任务。

Release checklist:

1. 将 CLI package 版本从 `0.4.9` bump 到 `0.4.10`。
2. 跑完本地 release quality gates。
3. 构建 publish artifact，并确认 dist manifest 报告 `0.4.10`。
4. 通过现有 tag-triggered GitHub release workflow 发布。
5. 验证 npm `latest` 解析到 `0.4.10`，并验证已发布 CLI 版本。
