## Background

The integrated session composer made file and image attachments feel too large
inside the input shell. File cards read as standalone content cards, and the
attachment tray sat too close to the composer outer border.

## Acceptance Criteria

- File and image previews use a more compact attachment-chip scale.
- Attachment previews keep enough breathing room from the composer border.
- File cards still preserve readable names, file kind, remove affordance and
  image lightbox access.
- Shared `SessionComposer` remains the single implementation consumed by
  Worker Web and Soul App surfaces.

## Completion

Completed in `PLAN-383`:

- Reduced file attachment card, icon and remove-button dimensions.
- Reduced image attachment preview dimensions while keeping lightbox preview.
- Increased attachment tray padding from the composer border.
