## 背景

`v0.18.1` 是当前 npm latest 与 GitHub latest release。本轮已完成
`FEAT-100 / PLAN-369`，将 HR People Workbench 右侧收敛为 profile-first
composer：移除 collapsed icon rail，Recent Sessions 置顶，composer 占满剩余高度，
默认生成 reviewable `profile-update-proposal`，并支持多文件候选人材料落到
workspace evidence 后随 session context/metadata 传入。

这是已发布 `0.18.1` 之后的 Web shell / official HR Soul App visible UX
修复与收敛，按 patch release 发布为 `0.18.2`。

## 范围

- 将 CLI package version 从 `0.18.1` bump 到 `0.18.2`。
- 运行本地 release gates，覆盖 full check/test/build、mounted-surface smoke、
  dist package、pack dry-run、dist release smoke 与 code-review-graph。
- 提交 release prep commit。
- 推送已合并的 HR composer commits、release prep commit 与 annotated tag
  `v0.18.2`。

  published-package smoke。
