# BUG-092 Worker Web icon button size drift

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-11 15:06
- **plan**: PLAN-250
- **relatesTo**: packages/component, apps/web

## Background

Worker Web add buttons and settings/refresh icon buttons used separate class
paths (`icon-only`, `settings-trigger`) with different box sizes. Add buttons
rendered larger than settings buttons, so the component-library direction was
not visible in the actual control surface.

## Goal

Unify add/settings/refresh icon buttons through a shared component primitive and
one size token.

## Acceptance Criteria

- Add a reusable `IconButton` primitive to `packages/component`.
- Route add/settings/refresh controls through `IconButton`.
- Define one icon-button size token and apply it consistently.
- Preserve existing behavior and accessibility labels.
- Run focused Web validation and code-review-graph before closure.
