# BUG-120 Release daemon reports dev runtime version

- **status**: completed

- **owner**: codex

- **relatesTo**: apps/cli, apps/api, apps/web, REL-032

## Description

A daemon started from the published `@zonease/aiworker-cli@0.13.1` package
reports `runtimeVersion: "dev"` through `/health` and `/api/local/info`.
Worker Web Settings reads the About version from `/api/local/info`, so a real
release daemon appears as a dev build in Settings.

Acceptance criteria:

- A release or dist CLI daemon reports the CLI package version through
  `/api/local/info.runtimeVersion`.
- `/health.runtimeVersion` and OpenAPI `info.version` use the same injected
  runtime version.
- Source-mode API bootstrap can still use the explicit `dev` fallback.
- The dist release smoke fails before the fix and passes after asserting the
  daemon version matches dist `package.json`.
- Existing CLI and API focused tests remain passing.

## ActiveForm

Fixing CLI daemon bootstrap so packaged AIWorker daemons expose the running
CLI package version to Host Web Settings and local daemon metadata routes.
