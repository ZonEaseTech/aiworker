## Acceptance Criteria

1. `aiworker engine select claude-code` 后，新 CLI session 记录
   `engineId: "claude-code"`，并把 `engineCommand` 解析为已安装的 `claude`
   executable 或其绝对路径。
2. CLI/API/Web 使用同一套 Host-owned local engine resolution contract。
3. 未知 engine id 或已知但未安装的 local engine 在 session 创建前得到清晰错误。
4. HR universal composer 默认 capability 的 hidden select value、可见 combobox label
   和 Start readiness 一致。
5. 第 6 轮及后续真实 E2E 可用 Playwright fallback 采集 mounted surface screenshot、
   layout、console 和 theme diagnostics。
6. Theme diagnostics 能记录 Host effective theme、mounted URL/data theme、browser
   color-scheme 来源和 mounted document theme state。
7. focused tests、`bun run ui:check`、Host/Soul boundary audit、browser evidence、
   code-review-graph 和 `git diff --check` 均完成或明确记录无法运行的原因。
