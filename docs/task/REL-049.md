## Background

`v0.18.2` is the current npm latest and GitHub Release. Local `main` contains
three unreleased commits after `v0.18.2`:

- `ff93c84a fix: 使用 PNG 品牌资产替换图标`
- `2da2dae6 chore: 强化共享组件治理门禁`
- `c3424fd0 fix: 收敛 HR profile composer right panel`

This patch release publishes those visible Web/UI and development-governance
changes as `@zonease/aiworker-cli@0.18.3`, then cleans the local worktree.

## Scope

- Bump CLI package version from `0.18.2` to `0.18.3`.
- Run local release gates covering check/test/build, mounted-surface smoke,
  dist package checks, pack dry-run, dist release smoke, UI governance, and
  code-review-graph.
- Push `main`, create and push annotated tag `v0.18.3`.
- Monitor the tag-triggered GitHub Actions release workflow and main lint
  workflow.
- Verify npm latest, explicit `bunx` version, GitHub Release assets, and
  published-package smoke.
- Record release evidence and leave the worktree clean.

## Non-goals

- Do not add new product changes during release prep.
- Do not rewrite release workflow or backfill older release docs.
- Do not publish without release workflow success.

## Acceptance

1. Local release gates pass.
2. `apps/cli/package.json` and `apps/cli/dist/package.json` report `0.18.3`.
3. `main` and `v0.18.3` are pushed.
4. GitHub Actions release workflow succeeds.
5. npm latest resolves to `0.18.3`.
6. `bunx @zonease/aiworker-cli@0.18.3 --version` reports `aiworker/0.18.3`.
7. GitHub Release `v0.18.3` exists with four binary tarballs and four matching

8. Published-package smoke proves the released CLI starts Host Web/API,

9. Local worktree is clean.
