## Context

`0.12.1` is a patch release for the Case-driven Project Brain loop after
FEAT-058. It carries correctness and production-readiness fixes after `0.12.0`:

- Case and Journal evidence is task-scoped instead of conversation-scoped.
- Pure heuristic observe-only pass no longer becomes `ready_to_ship`.
- Brain Engine reviewed pass can be used as release evidence, but high-risk
  ambient authority warning remains visible.
- Codex current native thread resume no longer replays old conversation turns
  into the executor context.

This is not a 1.0 GA release. The goal is to make the current pre-1.0 release
safe to ship as the validated Case-driven Brain loop baseline.

## Release Criteria

1. Source gates pass: `bun run check`, `bun run test`, `bun run build`.
2. `git diff --check` passes.
3. CLI source and dist manifest report `0.12.1`.
4. `cd apps/cli/dist && bun publish --dry-run --access public` reaches pack
   success.
5. A real source worker dogfood validates task-scoped Case, truthful review
   decision, lessons proposal, and native-resume prompt behavior where feasible.
6. GitHub Actions release workflow publishes npm and GitHub Release assets.
7. Published-package smoke confirms `@zonease/aiworker-cli@0.12.1`.
8. Published-package compact governance harness passes.
