# BUG-052 `orchestrator.text` emits duplicate final text after streamed deltas

- **status**: pending
- **priority**: P2
- **owner**: unassigned
- **createdAt**: 2026-05-04 02:07
- **discoveredAt**: 2026-05-04 02:01

## Observed Behavior

During remote Coder validation with the published `@zonease/aiworker-cli@0.5.3`
package and a real Claude Code executor, `aiworker run` successfully streamed
assistant text and finished normally. However, the CLI event stream emitted
incremental `orchestrator.text` payloads and then emitted the complete final
answer as another `delta` payload.

For a marker recall response, the observed text events were shaped like:

```json
{"type":"orchestrator.text","payload":{"delta":"AIWORKER_MARKER_"}}
{"type":"orchestrator.text","payload":{"delta":"20260504_CODER_RELEASE_01"}}
{"type":"orchestrator.text","payload":{"delta":"AIWORKER_MARKER_20260504_CODER_RELEASE_01"}}
```

A downstream client that treats every `payload.delta` as append-only text will
render duplicated content.

## Expected Behavior

`orchestrator.text` should have a clear append-only contract, or the event
payload should explicitly distinguish incremental deltas from a final full
snapshot. Worker Admin, CLI logs, gateway chat, QA tooling, and any SSE
consumer should be able to reconstruct assistant text without special
engine-specific duplicate suppression.

## Reproduction

Environment:

- Coder workspace: `ben/ben`
- Project directory:
  `/home/ben/projects/debug-aiworker/release-cli-claude-code`
- CLI under test: published `@zonease/aiworker-cli@0.5.3`
- Executor: `claude-code/default`
- Claude Code binary: `/home/ben/.npm-global/bin/claude`

Sanitized command sequence:

```bash
cd /home/ben/projects/debug-aiworker/release-cli-claude-code
npm install --prefix .npm-aiworker @zonease/aiworker-cli@0.5.3
PATH=/home/ben/.npm-global/bin:$PWD/.npm-aiworker/node_modules/.bin:$PATH \
  .npm-aiworker/node_modules/.bin/aiworker init --soul developer
PATH=/home/ben/.npm-global/bin:$PWD/.npm-aiworker/node_modules/.bin:$PATH \
  .npm-aiworker/node_modules/.bin/aiworker executor select --engine claude-code --apply
PATH=/home/ben/.npm-global/bin:$PWD/.npm-aiworker/node_modules/.bin:$PATH \
  .npm-aiworker/node_modules/.bin/aiworker run \
    --chat-id release-cli-claude-code-continuity \
    --timeout-ms 180000 \
    --message 'Remember this marker exactly: AIWORKER_MARKER_20260504_CODER_RELEASE_01. Reply with OK only.'
PATH=/home/ben/.npm-global/bin:$PWD/.npm-aiworker/node_modules/.bin:$PATH \
  .npm-aiworker/node_modules/.bin/aiworker run \
    --chat-id release-cli-claude-code-continuity \
    --timeout-ms 180000 \
    --message 'Reply with only the marker I asked you to remember.'
```

The second run continued the existing session and recalled the marker, but the
text event stream included both partial deltas and a final full-text `delta`.

## Acceptance Criteria

1. Decide and document whether `orchestrator.text.payload.delta` is append-only
   or whether full snapshots need a distinct payload field/event type.
2. Fix the narrowest layer that currently emits the final full answer as a
   `delta` after partial deltas.
3. Add focused coverage for Claude Code streaming where partial assistant text
   is followed by a final assistant message.
4. Verify `aiworker run` and Worker Admin chat can render a streamed response
   without duplicated text.
5. Preserve successful session continuation and redacted engine binding output.
