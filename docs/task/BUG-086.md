# BUG-086 Claude Code default profile forces a volatile model alias

## 描述

PLAN-144 的 source compact harness rerun 暴露出 Claude Code compact pair 全部
executor turns 失败：

`model 'claude-sonnet-4-6' not found or not supported`

失败不是 Project Brain governance 逻辑造成的，而是 AIWorker 的
`claude-code/default` profile 默认写死 `model: 'sonnet'`，并由 adapter 转发成
Claude Code CLI 的 `--model sonnet`。在当前 operator account / provider
环境下，该 alias 被外部 runtime 解析成不可用模型。

这违反轻量 Worker 边界：AIWorker 可以转发 operator 显式模型 hint，但不应该在
默认 profile 里替外部 executor runtime 固化 volatile model/provider routing。

## ActiveForm

让 `claude-code/default` 使用 Claude Code CLI 的 engine-native 默认模型。

## Dependencies

- **blocked by**: none
- **blocks**: source compact Governance Kernel harness stability
- **relates to**: lightweight Brain / executor-owned model boundary

## Evidence

- `tmp/governance-kernel-plan144-source-2/reports/governance-kernel-summary.json`
  overall FAIL。
- Claude Code turn logs show `API Error: 400` with
  `model 'claude-sonnet-4-6' not found or not supported`.
- The same run shows DB isolation queries themselves succeeded
  (`primary conversations=1`, `alternate conversations=1`, `separate=true`),
  but the alternate turn could not finish because the executor rejected the
  forced model.

## Expected Behavior

- `claude-code/default` does not pass `--model` unless the operator explicitly
  configures `model` or `modelId`.
- Explicit model overrides remain best-effort hints forwarded to the external
  CLI.
- Worker Admin and docs describe the default as CLI-owned, not Sonnet-owned.

## Non-Scope

- Do not change Codex defaults.
- Do not implement model discovery.
- Do not add fleet/gateway behavior.
- Do not treat AIWorker as the canonical executor model compatibility source.

## Resolution

Removed the default `model: 'sonnet'` from `claude-code/default`, updated Worker
Admin variant copy to say CLI default model, and documented the contract in
`docs/executor-engines.md`.

Explicit model overrides are unchanged: if an operator sets `model` /
`modelId`, AIWorker still forwards that value as a best-effort hint to Claude
Code.
