## Background

Review of the shared session composer exposed two operator-visible defects:

- file/image attachments could not be pasted into the composer;
- selecting files through the hidden file input was inconsistent, especially
  when selecting the same file again.

The desired UX is Codex Desktop-style: attachments live inside the composer
body, images render as preview tiles with lightbox support, and files render as
typed cards with a clear remove affordance.

## Acceptance Criteria

- Shared `SessionComposer` accepts pasted file/image clipboard payloads.
- HR profile, workspace new-session and session follow-up composers consume the
  shared paste callback instead of app-local paste behavior.
- File inputs remain programmatically clickable and clear stale value before
  opening so repeated same-file selection works.
- Attachment UI is composer-internal: image preview tiles and file cards render
  before the text input.
- Focused component and WorkerStudio tests cover paste, picker clearing,
  attachment cards and material submission.
- UI governance, focused web gates and code-review-graph review pass before
  closure.
