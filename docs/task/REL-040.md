## 背景

`QA-037 / PLAN-349` 已完成 HR app production readiness campaign，修复了
profile promotion、native skill artifact、official app defaults 和 engine asset
projection 的投产阻断问题。

当前 npm latest 为 `@zonease/aiworker-cli@0.17.0`。本任务发布 `0.17.1`
patch release，让已验证的 HR profile promotion 闭环进入 npm latest 与 GitHub
Release。

## 范围

- 将 CLI package version 从 `0.17.0` bump 到 `0.17.1`。
- 运行本地 release gates，覆盖 full check/test/build、dist package、pack
  dry-run 与 dist release smoke。
- 提交 release prep commit。
- 合并当前 release 分支到 `main`。
- 推送 `main` 与 annotated tag `v0.17.1`。
- 监控 tag-triggered GitHub Actions release workflow。
- 验证 npm latest、显式 `bunx` 版本、GitHub Release assets 与
  published-package smoke。
- 更新本任务、`PLAN-350`、索引文件与 `docs/changelog.md` 的 release
  evidence。

## 非范围

- 不扩展 HR app 功能范围。
- 不重写 `v0.17.0` tag 或 npm package。
- 不改变 Host/Soul App 协议边界。

## 验收标准

1. 本地 release gate 全部通过。
2. `apps/cli/package.json` 与 `apps/cli/dist/package.json` 均报告 `0.17.1`。
3. `npm pack --dry-run --json` 证明 HR production-readiness 修复后的 Worker
   Web、official HR/QA app resources 与 CLI dist 进入发布包。
4. `smoke:dist-release` 证明 dist CLI 能启动 Host Web/API、bootstrap official
   HR/QA Soul Apps，并成功调用 HR `create-people-profile` 与 QA
   `create-release-gate` mounted actions。
5. 当前分支合并到 `main`，且 `main` 与 `v0.17.1` 推送成功。
6. GitHub Actions release workflow 成功。
7. npm latest 解析到 `0.17.1`。
8. `bunx @zonease/aiworker-cli@0.17.1 --version` 报告 `aiworker/0.17.1`。
9. GitHub Release `v0.17.1` 存在且含四个平台 binary tarballs 和四个 matching
   `.sha256` checksum assets。
10. Published-package smoke 证明已发布 CLI 可启动 Host Web/API、bootstrap
    official HR/QA Soul Apps，并调用 HR/QA mounted actions。
