## 背景

`v0.18.0` 是当前 npm latest 与 GitHub latest release。本轮已完成
`FEAT-099 / PLAN-367`，将 `packages/component` 提升为 Host/Soul Web
共享组件与样式入口，迁移 Host Web 主要工作台/settings surfaces 到共享
primitives/patterns，并补齐 HR Soul App 直接消费共享组件库的证明。

发布前用户又反馈 engine icon 失效，本轮已将 engine card/icon 样式收回
`@zonease/aiworker-component/styles.css`，并扩展 mounted-surface smoke 覆盖
`[data-engine-icon="codex"] .agent-icon-shape` 的可见区域、mask 与 SVG 资源。

这些是已发布 `0.18.0` 之后的 Web shell、共享组件与可见 UI 稳定性修复，按
patch release 发布为 `0.18.1`。
