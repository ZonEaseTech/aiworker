## Context

`0.12.0` is a minor pre-1.0 release for the Worker Case operating surface:
Case File projection, Review Decision, Worker Case REST/CLI, Worker Admin Cases
UI, and fleet-hosted worker bridge support.

This is not a 1.0 GA release. The release should prove the Worker Case flow is
shippable as the current source MVP while preserving the BYO executor and
Project Brain boundaries.

## Release criteria

- Source gates pass: `bun run check`, `bun run test`, `bun run build`.
- `git diff --check` passes.
- CLI version and bundled manifest report `0.12.0`.
- `bun publish --dry-run --access public` reaches pack/dry-run success.
- Local installed/package smoke confirms `aiworker --version` and Case commands.
- Governance harness / compact validation is rerun or explicitly recorded with
  the reason it could not run.
- No full Case File payload is persisted to `fleet.db`; Fleet bridge remains
  transit-only.
