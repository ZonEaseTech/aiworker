## 背景

`@zonease/aiworker-cli@0.10.3` 是当前 npm latest 与最新 GitHub Release。
`v0.10.3..HEAD` 已包含：

- native executor skill placement：默认 Project Brain skills 不再进入
  `.aiworker/skills/` 主路径，而是写到 `.agents/skills/` 与 `.claude/skills/`。
- managed native skill projection lifecycle：`aiworker-*` managed namespace、
  `.aiworker/native-skill-projections.json`、`brain skills sync-native`、
  drift/deprecate/orphan reporting。

本次按 patch release 发布 `0.10.4`，并在发布后验证已发布 package。

## 范围

- 将 `apps/cli/package.json` 与 README latest 更新到 `0.10.4`。
- 运行本地 release gate。
- 构建并检查 CLI dist 产物版本。
- 执行 publish dry-run 到本机 npm auth boundary。
- 提交 release bump。
- 推送 `main` 与 annotated tag `v0.10.4`。
- 监控 tag-triggered GitHub Actions release workflow。
- 验证 npm latest、显式 package smoke、GitHub Release assets。
- 运行发布包 `cli-release-local` compact harness。
- 修正 release harness 对 `brain-skill-add` 的断言，使其验证 native executor
  project skill projection 与 manifest，而不是旧的 `.aiworker/skills` canonical
  file。

## 非范围

- 不修改 runtime 行为。
- 不改变 release workflow。
- 不做 fleet/gateway 远端升级。

## 验收标准

1. 本地 release gate 全部通过。
2. `main` 与 `v0.10.4` 推送成功。
3. GitHub Actions release workflow 成功。
4. npm latest 解析到 `0.10.4`。
5. `bunx @zonease/aiworker-cli@0.10.4 --version` 报告 `aiworker/0.10.4`。
6. GitHub Release `v0.10.4` 存在且含四个平台 binary assets。
7. 发布包 `cli-release-local` compact harness 通过，或记录明确 finding / blocker。
