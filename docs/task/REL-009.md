## 描述

发布 `@zonease/aiworker-cli@0.5.0`，作为 `0.4.11` 之后的 minor release，并把测试服 gateway/fleet 升级到该版本。

本次发版包含 `0.4.11` 之后已合入 main 的改动：

- REFACTOR-015 / PLAN-062：CLI root shortcut 收敛为本地 worker，远端控制面迁到 `fleet`，gateway 生命周期迁到 `gateway`。
- FEAT-045 / PLAN-063：新增 `aiworker up` / `aiworker worker up` 本地 worker 快速启动路径。

Release checklist：

1. 把 CLI package 版本从 `0.4.11` bump 到 `0.5.0`。
2. 跑完本地 release quality gates。
3. 构建 publish artifact，并确认 `apps/cli/dist/package.json` 报告 `0.5.0`。
4. 通过现有 tag-triggered GitHub release workflow 发布。
5. 验证 npm `latest` 解析到 `0.5.0`，并 smoke 已发布 CLI。
6. 使用 `aissh` 升级测试服 gateway/fleet 到 `0.5.0`，验证服务状态、gateway `/health` 与 CLI version。
