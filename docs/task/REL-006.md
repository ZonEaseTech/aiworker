## Description

发布 `@zonease/aiworker-cli@0.4.9`，作为 `0.4.8` 之后的 patch release。

本次发版包含 `0.4.8` 之后已合入 main 的改动：

- `npx` / `bunx` 启动入口优化：npm 包的 `aiworker` bin 变为 shell shim，真实 Bun bundle 改为 `aiworker-bun.js`。
- 无 Bun runtime 时输出清晰安装与 standalone binary 提示，不再暴露原始 shebang 错误。
- `aiworker init` 允许在非 git 目录初始化项目级 `.aiworker/` 布局。
- CLI 全局 help 改为中文场景分组和使用引导，并同步收敛命令与 option 描述。

Release checklist:

1. 将 CLI package 版本从 `0.4.8` bump 到 `0.4.9`。
2. 跑完本地 release quality gates。
3. 构建 publish artifact，并确认 dist manifest 报告 `0.4.9`。
4. 通过现有 tag-triggered GitHub release workflow 发布。
5. 验证 npm `latest` 解析到 `0.4.9`，并验证已发布 CLI 版本。
