## Description

针对 `@zonease/aiworker-cli@0.7.0` published 版本，使用 claude-code 2.1.126 executor (sonnet model)，做端到端调试，重点对比 0.6.0 → 0.7.0 修复情况 + 探索新缺陷。

调试规模：

- 9 个 Soul preset × 10 类 prompt = **91 次真实 LLM 采样**（含 1 次 smoke）
- 3 个 Soul × 2 (with/no brain) = **6 次 brain 注入对照实验**
- 5 次 Phase 6 LLM evaluator subprocess dump
- Phase 7 worker REST 全 endpoint smoke
