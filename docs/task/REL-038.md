# REL-038 发布 aiworker CLI 0.16.1

- **status**: completed
- **priority**: P0
- **owner**: codex
- **createdAt**: 2026-05-16
- **claimedAt**: 2026-05-16
- **completedAt**: 2026-05-16
- **plan**: PLAN-338
- **relatesTo**: BUG-123, PLAN-337, v0.16.0

## 背景

`@zonease/aiworker-cli@0.16.0` 的 published package 会把官方 HR/QA Soul App
manifest 指向不存在的 `dist/host-mounted.js`。真实 Bun build 输出为
`dist/mounted/host-mounted.js`，导致 Host mounted action 启动 app service 时 502，
用户可见症状是点击 HR header slot 的 `create-people-profile` button 后失败。

`BUG-123 / PLAN-337` 已修复 source 与 dist smoke 覆盖；本任务发布 `0.16.1`
patch，让 npm latest 与 GitHub Release 携带该修复。

## 范围

- 将 CLI package version 从 `0.16.0` bump 到 `0.16.1`。
- 运行本地 release gates，重点覆盖 official HR/QA mounted action dist smoke。
- 提交 release prep commit。
- 推送 `main` 与 annotated tag `v0.16.1`。
- 监控 tag-triggered GitHub Actions release workflow。
- 验证 npm latest、显式 `bunx` 版本、GitHub Release assets 与 published-package smoke。
- 更新本任务、`PLAN-338`、索引文件与 `docs/changelog.md` 的 release evidence。

## 非范围

- 不新增 Soul App authoring surface。
- 不重写 `v0.16.0` tag 或 npm package。
- 不改变 Host/Soul App 协议边界。
- 不处理与 BUG-123 无关的 UI 或 daemon 行为。

## 验收标准

1. 本地 release gate 全部通过。
2. `apps/cli/package.json` 与 `apps/cli/dist/package.json` 均报告 `0.16.1`。
3. `npm pack --dry-run --json` 证明官方 HR/QA app release resources 进入发布包。
4. `smoke:dist-release` 证明 dist CLI 能启动 Host Web/API、bootstrap official
   HR/QA Soul Apps，并成功调用 HR `create-people-profile` 与 QA
   `create-release-gate` mounted actions。
5. `main` 与 `v0.16.1` 推送成功。
6. GitHub Actions release workflow 成功。
7. npm latest 解析到 `0.16.1`。
8. `bunx @zonease/aiworker-cli@0.16.1 --version` 报告 `aiworker/0.16.1`。
9. GitHub Release `v0.16.1` 存在且含四个平台 binary tarballs 和四个 matching
   `.sha256` checksum assets。
10. Published-package smoke 证明已发布 CLI 的 HR/QA mounted action path 可用。

## 残余风险

- 已发布 `0.16.0` 仍然有该 502 问题；用户需要升级到 npm latest `0.16.1`
  或显式使用 `@zonease/aiworker-cli@0.16.1`。
- GitHub Actions release workflow 仍报告既有 Node.js 20 actions deprecation
  annotation，涉及 `actions/setup-node@v4` 和 `softprops/action-gh-release@v2`。
  该注解未阻塞 `0.16.1` 发布。
