## 背景

上一次将 add actions 收敛为 plus + label pill 后，用户要求回归到 plus icon button，并且
将 workspace rail 里的“新建工作区 / 新建会话”也替换成同样的 plus icon button。

## 目标

所有 add 类型入口统一为 `IconButton` 的 plus icon-only 样式。

## 验收标准

- Worker 列表创建入口使用 plus `IconButton`。
- Worker home 工作区列表创建入口使用 plus `IconButton`。
- Workspace rail 的“新建会话”和“新建工作区”使用 plus `IconButton`。
- 按钮保留 `aria-label` / `title`，不依赖可见文字表达语义。
- 更新测试、浏览器验证和 code-review-graph 审查记录。
