# BUG-099 Select 打开态与选项样式割裂

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-11 17:49
- **plan**: PLAN-257
- **relatesTo**: packages/component, apps/web

## 背景

Worker Web 的 `StudioSelect` 在创建 worker 对话框和工作区会话创建器中样式不一致：
折叠态、展开态和 option list 看起来像不同组件拼接，展开时圆角割裂，列表层级也容易被
dialog 容器裁切。

## 目标

把 select trigger、展开列表和 option 统一成同一套组件盒模型，并修复展开层级问题。

## 验收标准

- Select 折叠态保持现有紧凑输入样式。
- Select 展开态 trigger 和 listbox 的边框、圆角、层级连续。
- Option hover/active 使用统一的 token 化背景、边框和圆角。
- 创建 worker dialog 中的 select list 不再被容器裁切。
- 更新测试、浏览器验证和 code-review-graph 审查。
