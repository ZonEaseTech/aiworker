# BUG-014 `aiworker install systemd` 渲染的 unit 缺 `EnvironmentFile` + 全部安全加固

- **status**: pending
- **priority**: P2
- **owner**: (unassigned)
- **createdAt**: 2026-04-27 12:25
- **discovered**: 2026-04-27 11:23 — REFACTOR-004 cutover 时跑 `aiworker install systemd --system --dry-run` 看到渲染产物，发现缺关键字段。

## Description

当前 `aiworker install systemd --system --dry-run` 输出：

```ini
[Unit]
Description=AIWorker gateway daemon (system instance)
After=network.target

[Service]
Type=simple
ExecStart=/root/.bun/bin/aiworker gateway start
Restart=on-failure
RestartSec=5
Environment=AIWORKER_HOME=/var/lib/aiworker

[Install]
WantedBy=multi-user.target
```

对比 REFACTOR-004 cutover 实测保留的 prod unit（PLAN-016 时手写）：

```ini
[Service]
Type=simple
EnvironmentFile=/etc/aiworker/gateway.env       ← 缺！master key / shared secret 注入
ExecStart=/root/.bun/bin/aiworker gateway start
WorkingDirectory=/opt/aiworker                  ← 不需要（已删）
Restart=on-failure
RestartSec=5
User=root
Group=root
StateDirectory=aiworker                         ← 缺！自动建 /var/lib/aiworker
StateDirectoryMode=0700                         ← 缺！
PrivateTmp=true                                 ← 缺！
ProtectSystem=strict                            ← 缺！
ReadWritePaths=/var/lib/aiworker                ← 缺！
NoNewPrivileges=true                            ← 缺！
```

### 用户可见影响

新 deployer 跑 `aiworker install systemd --system` 一键部署时：

1. **Service 起不来**：缺 `EnvironmentFile` → `AIWORKER_MASTER_KEY` / `INTERNAL_SHARED_SECRET` 没注入 → schema validation fail → exit 1。**完全 blocking** — REFACTOR-004 想要的 "一行命令部署" 不成立。
2. **若 deployer 把 secret 写 `Environment=` 行**（变通方案）：明文 secret 落 systemd unit 文件 → `systemctl cat` 可见 → 违反 secret 管理原则。
3. **缺安全加固**：service 跑 root 没 ProtectSystem / PrivateTmp / NoNewPrivileges → 沙箱面被裸露 → 一旦 worker / gateway 被入侵，攻击者拿到完整 root 权限。
4. **没 StateDirectory**：deployer 必须手工 `mkdir -p /var/lib/aiworker` 才能跑（fleet.db 写不动）。

### Acceptance criteria

1. `aiworker install systemd --system --dry-run` 渲染的 unit 内容**等价**于 REFACTOR-004 cutover 时 in-use prod unit（删 WorkingDirectory 即可）：
   ```ini
   [Unit]
   Description=AIWorker gateway daemon (PLAN-016 systemd path)
   Documentation=https://github.com/ZonEaseTech/aiworker/blob/main/docs/deployment.md
   After=network-online.target
   Wants=network-online.target

   [Service]
   Type=simple
   EnvironmentFile=-/etc/aiworker/gateway.env
   ExecStart=/root/.bun/bin/aiworker gateway start
   Restart=on-failure
   RestartSec=5
   User=root
   Group=root
   StateDirectory=aiworker
   StateDirectoryMode=0700
   PrivateTmp=true
   ProtectSystem=strict
   ReadWritePaths=/var/lib/aiworker
   NoNewPrivileges=true

   [Install]
   WantedBy=multi-user.target
   ```
   注意 `EnvironmentFile=-/etc/aiworker/gateway.env`（前置 `-` 让文件不存在时不 fail，方便 first-run；deployer 后续填充）。
2. `--user` 形态同步加加固（`User`/`Group` 自动 sudo-less，但 `StateDirectory` / `ProtectSystem` 也应有；用户实例的 `StateDirectory` 走 `~/.local/state/aiworker`）。
3. 命令 first-run 后输出 banner 提示 deployer 创建 `/etc/aiworker/gateway.env` 并写入 master key + shared secret（推荐 `openssl rand -hex 32` / `openssl rand -base64 24`），并保护权限 `chmod 600` + `chown root:root`。
4. 添加 unit-template integration test：渲染 unit 跑 `systemd-analyze verify <file>`（CI 安装 systemd-analyze），验证语法 + 加固 directive 全在。
