# BUG-098 Workspace route should focus on session creation

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-11 17:26
- **plan**: PLAN-256
- **relatesTo**: apps/web

## Background

`workspaces/[workspace_id]` should not act like another management overview
page when no session is selected. The operator has already selected a
workspace from the worker page and the side rail already owns session
navigation.

## Goal

When the workspace route is open without a selected session, make the main
surface focus on creating a new session with a Codex-like composer.

## Acceptance Criteria

- Remove the workspace overview and central session card grid added in
  BUG-097.
- Keep session navigation in the workspace side rail.
- Replace the main workspace body with a centered create-session composer.
- Preserve create-session streaming and navigation to the new session.
- Update tests, PMA docs, browser verification, and code-review-graph review.
