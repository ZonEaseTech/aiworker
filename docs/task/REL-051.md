## Background

`v0.18.4` is the current npm latest and GitHub Release.

Current `main` contains the Session Kit work and follow-up fixes after
`v0.18.4`:

- shared Session composer, attachment list, action bar, timeline, markdown and
  message-flow patterns;
- Codex CLI session activity parsing and normalized timeline view models;
- composer file/image input, paste support, lightbox preview, dedupe, busy
  state, attachment clearing and usage meter integration;
- HR and generic session surfaces consuming the shared composer kit;
- Host/Soul configuration terminology cleanup;
- MCP legacy-entrypoint cleanup before real workspace MCP binding work begins.

This is a 0.x minor release because the public Worker Web session/composer
experience and shared component surface changed materially.

## Scope

- Bump CLI package version from `0.18.4` to `0.19.0`.
- Run local release gates covering check/test/build, mounted-surface smoke,
  dist package checks, pack dry-run, dist release smoke, UI governance, docs
  contract and code-review-graph.
- Push `main`, create and push annotated tag `v0.19.0`.
- Monitor the tag-triggered GitHub Actions release workflow and main lint
  workflow.
- Verify npm latest, explicit `bunx` version, GitHub Release assets and
  published-package smoke.
- Record release evidence and leave the worktree clean.

## Non-goals

- Do not add product changes during release prep.
- Do not publish SDK/runtime packages separately.
- Do not rewrite the release workflow.
- Do not publish without release workflow success.
