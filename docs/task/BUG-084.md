# BUG-084 Docker image build still assumes removed apps/gateway package

- **status**: completed
- **priority**: P1
- **owner**: local
- **createdAt**: 2026-05-06 14:54
- **claimedAt**: 2026-05-06 14:54
- **completedAt**: 2026-05-06 14:59
- **plan**: PLAN-142

## 描述

`build-image` GitHub workflow 在 release commit `01372c8` 的 main push 上失败，
因为 Dockerfile 仍复制已不存在的 `apps/gateway/package.json`。

实际仓库布局里 gateway 已迁到 `packages/gateway`，包名为
`@zonease/aiworker-gateway`。Dockerfile、compose command 和当前部署文档仍保留
旧 `apps/gateway` 路径，导致镜像构建无法通过。

## ActiveForm

修复 Docker image 对旧 `apps/gateway` 路径的依赖

## Dependencies

- **blocked by**: none
- **blocks**: main `build-image` workflow
- **relates to**: BUG-012, REFACTOR-004, REL-021

## Evidence

- `gh run view 25442359470 --log-failed` 显示 Docker build 在
  `COPY apps/gateway/package.json apps/gateway/` 失败：
  `"/apps/gateway/package.json": not found`。
- 仓库实际存在 `packages/gateway/package.json`。
- `ops/compose/docker-compose.yml` 仍用 `bun apps/gateway/src/index.ts`。

## Resolution

- Dockerfile now copies `packages/gateway/package.json` during dependency
  installation and `/app/packages/gateway` into the runtime image.
- Compose now starts gateway with `bun packages/gateway/src/index.ts`.
- Current gateway/deployment/architecture docs now point at `packages/gateway`.
- Fix commit: `7c6f0ca`.

## 范围

- 修正 Dockerfile 中 gateway package manifest、runtime source copy 和注释路径。
- 修正 compose gateway command。
- 同步当前部署/架构文档中的 gateway 实现路径和 compose 命令。

## 非范围

- 不修改历史 changelog、旧 plan/task 中作为历史事实出现的 `apps/gateway`。
- 不重构 Dockerfile 分层结构。
- 不改变 npm release 或 `v0.9.5` tag。
