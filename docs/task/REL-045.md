# REL-045 发布 aiworker CLI 0.17.6

- **status**: in_progress
- **priority**: P0
- **owner**: codex
- **createdAt**: 2026-05-18
- **claimedAt**: 2026-05-18
- **plan**: PLAN-363
- **relatesTo**: v0.17.5, BUG-137, PLAN-362, 2bee1f18

## 背景

`v0.17.5` 发布后，用户反馈 Host left panel toggle icon 在激活状态下没有
像 HR toggle 一样高亮。`BUG-137 / PLAN-362` 已修复 Host shell
topbar left sidebar toggle 的 pressed state，使其命中共享 active icon
button 样式合同。

当前 npm latest 为 `@zonease/aiworker-cli@0.17.5`，远端最新 `v0.17.x`
tag 为 `v0.17.5`。本任务发布 `0.17.6` patch release。

## 范围

- 将 CLI package version 从 `0.17.5` bump 到 `0.17.6`。
- 运行本地 release gates，覆盖 full check/test/build、dist package、pack
  dry-run、dist release smoke 与 code-review-graph。
- 提交 release prep commit。
- 推送修复 commit、release prep commit 与 annotated tag `v0.17.6`。
- 监控 tag-triggered GitHub Actions release workflow。
- 验证 npm latest、显式 `bunx` 版本、GitHub Release assets 与
  published-package smoke。
- 更新本任务、`PLAN-363`、索引文件与 `docs/changelog.md` 的 release
  evidence。

## 非范围

- 不纳入主工作区当前未提交的 `BUG-136 / PLAN-361` profile-ledger 变更。
- 不继续扩大 Host shell 或 HR workbench UI 改造。
- 不重写 `v0.17.5` tag 或 npm package。

## 验收标准

1. 本地 release gate 全部通过。
2. `apps/cli/package.json` 与 `apps/cli/dist/package.json` 均报告 `0.17.6`。
3. `npm pack --dry-run --json` 证明 Worker Web、official HR/QA app resources
   与 CLI dist 进入发布包。
4. `smoke:dist-release` 证明 dist CLI 能启动 Host Web/API、bootstrap official
   HR/QA Soul Apps，并成功调用 HR/QA mounted actions。
5. `main` 与 `v0.17.6` 推送成功。
6. GitHub Actions release workflow 成功。
7. npm latest 解析到 `0.17.6`。
8. `bunx @zonease/aiworker-cli@0.17.6 --version` 报告 `aiworker/0.17.6`。
9. GitHub Release `v0.17.6` 存在且含四个平台 binary tarballs 和四个 matching
   `.sha256` checksum assets。
10. Published-package smoke 证明已发布 CLI 可启动 Host Web/API、bootstrap
    official HR/QA Soul Apps，并调用 HR/QA mounted actions。
