# BUG-159 Mounted app stylesheet overrides Host dark theme

- **status**: completed
- **priority**: P1
- **owner**: Codex
- **createdAt**: 2026-05-26
- **completedAt**: 2026-05-26
- **plan**: PLAN-416
- **relatesTo**: MOUNT-001, UI-001

## 背景

第 5 轮真实 E2E 后，Worker Web 在 `appearance: system` 且系统偏好为
dark 时仍出现主题撕裂：Host shell 外层显示浅色，而 mounted HR universal
workbench 显示深色。浏览器复现确认 Host 已设置 `html.dark` 且 mounted URL/data
为 `theme=dark`，但后加载的 mounted Soul App stylesheet 含全局 `:root` light
tokens，覆盖了 Host 的 `.dark` theme variables。

## 验收标准

1. [x] Host dark theme variables 不会被后加载的 mounted app `:root` 覆盖。
2. [x] Mounted micro-app HTML 在 dark theme 下提供 body-level `dark` ancestor，
       避免 micro-app 剥离 child `<html>` 后丢失 `dark:` 变体作用域。
3. [x] HR/QA official mounted adapters 和 universal workbench runtime 均有回归测试。
4. [x] UI governance 能阻止暗色 token 退回低优先级 `.dark` selector。
5. [x] 真实浏览器在 `http://127.0.0.1:5173` 下验证 dark/light system
       appearance 不再撕裂。
