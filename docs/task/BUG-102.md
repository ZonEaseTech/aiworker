# BUG-102 工作区侧栏存在多余返回 worker 动作

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-11 18:13
- **plan**: PLAN-260
- **relatesTo**: apps/web

## 背景

Workspace 侧栏进入工作区上下文后仍显示“返回 worker”。当前层级已经以工作区为主体，
session 详情只需要保留“返回工作区”动作，worker 级返回会增加不必要的导航噪声。

## 目标

移除 workspace 侧栏里的“返回 worker”入口。

## 验收标准

- workspace route 不显示“返回 worker”按钮。
- session route 不显示“返回 worker”按钮。
- session route 仍保留“返回工作区”按钮。
- 清理不再使用的 i18n 文案字段。
- 更新测试、浏览器验证和 code-review-graph 审查。
