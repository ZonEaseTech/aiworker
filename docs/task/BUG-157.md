2. HR mounted universal workbench can recover to the created or completed session after stream startup or consumption failure.
3. Universal composer initializes the visible capability selector from the default available template and enables Start after direct prompt entry.
4. Worker Configuration entry-file controls remain reachable at 390px width.
5. Duplicate visible worker names include stable Host metadata in the worker row and accessible labels.
6. Legacy `/api/local/artifacts` requests are removed from the HR mounted boot path or intentionally supported without creating a Host artifact product surface.
7. Focused tests, UI governance, Host/Soul boundary checks, browser evidence, and code-review-graph are recorded at closeout.
