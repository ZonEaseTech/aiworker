# BUG-108 Worker home add actions use icon-only buttons

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-12 01:33
- **plan**: PLAN-266
- **relatesTo**: apps/web

## 背景

Worker home 中 Worker 列表和工作区列表的 add 动作仍是裸 `IconButton`。它们与 rail
里的“新建会话 / 新建工作区”plus + label pill button 风格不一致。

## 目标

将这两处 add icon-only 入口统一为带文字的 pill action button。

## 验收标准

- Worker 列表创建入口使用 plus + label 的 `rail-mini-action` 样式。
- 工作区列表创建入口使用 plus + label 的 `rail-mini-action` 样式，并显示“新建工作区”。
- Refresh/settings 这类 chrome 操作仍保持 icon-only。
- 更新测试、浏览器验证和 code-review-graph 审查记录。
