## 背景

`@zonease/aiworker-cli@0.13.1` 已经发布：

- npm latest 当前返回 `0.13.1`。
- 本地与远端均存在 `v0.13.1` tag。
- GitHub Release `v0.13.1` 为 non-draft / non-prerelease，并包含四个平台
  binary assets。

当前本地 `main` 在 `origin/main` 之后有 13 个提交，包含开发版 home 隔离、
Soul App authoring boundary、release daemon runtime version propagation 与 Soul
App Web Storage discipline。由于 `0.13.1` 已发布，不能重复使用同一个版本号。
本次发布目标应为 patch release `0.13.2`。

## 范围

- 将 CLI package version 从 `0.13.1` bump 到 `0.13.2`。
- 运行本地 source/build/dist/pack/smoke release gates。
- 提交 release prep commit。
- 推送 `main` 与 annotated tag `v0.13.2`。
- 监控 tag-triggered GitHub Actions release workflow。
- 验证 npm latest、显式 package smoke、GitHub Release assets 与 published-package
  preview smoke。
- 更新本任务、`PLAN-322` 与 `docs/changelog.md` 的 release evidence。

## 非范围

- 不发布 `@zonease/aiworker-soul-app-sdk` 或
  `@zonease/aiworker-soul-app-runtime` 独立 npm 包。
- 不声明 1.0 GA。
- 不新增 Host auth、cloud marketplace、gateway/fleet 或远程控制面 scope。
- 不重写 `0.13.1` release tag 或 npm package。

1. 本地 release gate 全部通过。
2. `apps/cli/package.json` 与 `apps/cli/dist/package.json` 均报告 `0.13.2`。

   migrations 与官方 HR/QA app release resources 进入发布包。
4. `smoke:dist-release` 证明 dist CLI 能启动 Host Web/API 并 bootstrap official
   HR/QA Soul Apps。
5. `main` 与 `v0.13.2` 推送成功。
6. GitHub Actions release workflow 成功。
7. npm latest 解析到 `0.13.2`。
8. `bunx @zonease/aiworker-cli@0.13.2 --version` 报告 `aiworker/0.13.2`。
9. GitHub Release `v0.13.2` 存在且含四个平台 binary assets。
10. Published-package smoke 证明已发布 CLI 的 Host/Soul App preview path 可用。
