## 背景

`@zonease/aiworker-cli@0.13.1` 已经发布：

- npm latest 当前返回 `0.13.1`。
- 本地与远端均存在 `v0.13.1` tag。
- GitHub Release `v0.13.1` 为 non-draft / non-prerelease，并包含四个平台
  binary assets。

当前本地 `main` 在 `origin/main` 之后有 13 个提交，包含开发版 home 隔离、
Soul App authoring boundary、release daemon runtime version propagation 与 Soul
App Web Storage discipline。由于 `0.13.1` 已发布，不能重复使用同一个版本号。
本次发布目标应为 patch release `0.13.2`。
