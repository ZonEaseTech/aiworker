## Background

The layout refactor touches shared Worker Web chrome and therefore needs route
comparison, responsive validation, and regression coverage beyond static code
inspection.

## Goal

Validate that worker home, workspace, and session routes share consistent layout
chrome while preserving current route behavior and responsive scrolling.

## Acceptance Criteria

- Playwright MCP validates `/workers/:workerId`,
  `/workers/:workerId/workspaces/:workspaceId`, and
  `/workers/:workerId/workspaces/:workspaceId/sessions/:sessionId`.
- Desktop inspection confirms shared sidebar/main geometry across worker and
  workspace routes.
- 390px mobile inspection reports no horizontal overflow and usable scroll
  ownership.
- Existing settings, create worker, create workspace, create session, and
  session navigation tests continue to pass.
- code-review-graph result is recorded before completion.
