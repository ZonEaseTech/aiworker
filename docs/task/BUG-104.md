# BUG-104 Settings 引擎卡片缺少专属 icon

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-11 20:23
- **plan**: PLAN-262
- **relatesTo**: apps/web

## 背景

Settings dialog 的本地 CLI 引擎卡片使用通用 Sparkles / 灰色占位 icon，Codex、Claude
Code、Cursor、Gemini、OpenCode、Qwen 等 engine 没有各自的专属识别图形。

## 目标

拉取每个 engine 的专属 SVG icon，并替换对应 engine card 的通用 icon。

## 验收标准

- Codex、Claude Code、Cursor、Gemini、OpenCode、Qwen 都有本地 SVG icon。
- 兼容已有 Hermes / Hermes Agent engine id 的本地 SVG icon。
- Engine card 根据 engine id 渲染对应 icon。
- 未安装 engine 仍显示对应 icon，但视觉弱化。
- 图标资产不依赖运行时外链。
- 更新测试、浏览器验证和 code-review-graph 审查。

## Icon 来源

- LobeHub Icons CDN: OpenAI, Claude, Cursor, Gemini, OpenCode, Qwen, Hermes Agent.
