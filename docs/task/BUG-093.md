# BUG-093 Worker Web redundant execution readiness rail card

- **status**: completed
- **priority**: P0
- **owner**: local
- **createdAt**: 2026-05-11 16:16
- **plan**: PLAN-251
- **relatesTo**: apps/web

## Background

Worker Web rendered a persistent `readiness-card ready` section in the left rail
for execution status and a Settings shortcut. The same configuration surface is
already available through the header settings button, the footer execution pill,
and the Settings dialog execution section. Blocked execution is also surfaced
inline next to the disabled session creation action.

## Goal

Remove the redundant left-rail execution readiness section so the rail stays
focused on worker/workspace navigation and does not duplicate configuration
entrypoints.

## Acceptance Criteria

- Remove the left-rail readiness card from Worker Studio.
- Keep blocked execution feedback near session creation.
- Keep execution configuration available through existing Settings entrypoints.
- Remove unused readiness card styles and unused i18n copy.
- Run focused Web validation and code-review-graph before closure.
