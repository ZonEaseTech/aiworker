# CLI 0.13.0 Preview Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish and validate `@zonease/aiworker-cli@0.13.0` as the first preview minor release for the packaged Host Web/API plus bundled official HR/QA Soul App runtime path.

**Architecture:** Keep the release scoped to the CLI package. The CLI package carries Host runtime resources, Worker Web static assets, worker DB migrations and bundled official HR/QA app runtime resources; independent SDK/runtime npm packages remain out of scope.

**Tech Stack:** Bun workspaces, AIWorker CLI, local Host daemon, npm package publication, GitHub Actions release workflow, GitHub Release assets, PMA docs.
