# Local Shell Engine Bridge Phase 3F Scaffold Micro-App Defaults Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make newly scaffolded Soul Apps default to micro-app UI and app-owned mounted API paths, not Host workbench protocol descriptors.

**Architecture:** Host keeps start, shell, locate, mount and bridge. Generated Soul Apps own their UI/API through micro-app HTML and mounted local API paths. `ui.workbench` remains schema-compatible but is not generated by default.

**Tech Stack:** Bun CLI, TypeScript tests, Soul App manifest schema, generated Host-mounted service template.
